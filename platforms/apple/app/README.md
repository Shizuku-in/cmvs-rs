# CMVS Apple 启动器

启动器适用于 macOS 14 及以上版本，以及 iOS / iPadOS 17 及以上版本。从源码构建请参阅 [Apple 构建指南](../README.md)。

## 第一次启动游戏

1. 打开「游戏库」，点「添加游戏」，选择包含 `data/pack` 的游戏根目录。macOS 也支持把目录拖进游戏库。iOS 可选「引用目录」从原位置读取，或选「复制到游戏库」将文件保存到应用的 Application Support 目录。
2. 打开「字体」选择默认字体。macOS 和 iOS / iPadOS 会列出游戏可用的系统字体。也可以点「导入字体」，选择不超过 32 MiB 的 TTF、OTF 或 TTC 文件。字体合集中的每个字面都可单独选择。
3. 回到「游戏库」，点游戏卡片上的「启动」。需要为某款游戏更改字体、文本编码或渲染器时，点同一卡片上的「配置」。默认渲染器为 Metal，也可手动选择 CPU。

## 播放操作

| 操作 | macOS | iOS / iPadOS |
|---|---|---|
| 推进对话 | 左键或回车 | 单指轻点 |
| 打开游戏菜单 | 右键 | 双指轻点 |
| 翻阅履历 | 滚动鼠标滚轮 | 双指上下滑动 |
| 截图 |「游戏」菜单 →「截图」| 在快捷操作条中点「截图」 |
| 返回游戏库 | ⌘W 关闭播放器窗口 | 在快捷操作条中点「返回游戏库」 |

点右上角的省略号可展开快捷操作条，分别开关 Shift 快进和 Ctrl 快进，也可隐藏对话框。开启「多指手势」后也可用三指轻点展开操作条。macOS 可用 ⌘O 添加游戏、⌃⌘F 切换全屏。

遇到触摸或帧率问题时，在操作条点「开始调试记录」。复现后点「停止并导出调试记录」，再通过分享面板导出最近 30 秒的 JSON。

## 存档与备份

退出播放器后，在「存档」页找到游戏，点「导出 ZIP」并选择保存位置。迁移到另一台设备时，先添加同一款游戏，再点「从 ZIP 恢复」。确认后会替换同名存档。ZIP 对字体只保存引用，目标设备缺少对应字体时会使用默认字体。

| 平台 | 存档与截图目录 |
|---|---|
| macOS | `~/Library/Application Support/org.cmvs.player/` |
| iOS / iPadOS | 应用的 `Documents/`，可通过「文件」App 访问 |

各游戏的存档位于 `Saves/` 下，逻辑画面截图位于 `Screenshots/`。macOS 可在单游戏「配置」中启用「使用游戏内 savedata 目录」。首次迁移保留游戏目录中已有的同名文件。
