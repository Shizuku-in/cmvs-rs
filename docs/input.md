## 二进制证据

地址绑定 `cmvs64.exe` SHA-256 `dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5`，本次只读核对，未修改 IDB。

- `0x140054b20` 清零 +944 的 24×5 个 u16 绑定码。
- `0x140057740`（IDA 自动名字 setlocale_set_cat，与实际功能无关）从根目录 `key.cfg` 的 `KEY_FUNCTION_01..24`、`KEY_DATA_01..05` 填写绑定表，缺失为 0，大于 127 的码置 0；也有按 `KD_Function%z2%z2` 读取注册表覆盖的分支。调用点为 `0x140011bba`。
- `0x140019430` 读取设备与指针，更新输入码计数，再调用 `0x140055260` 派生动作状态。
- `0x140056780`：码 1/2/3 为鼠标左/中/右，4/5 为滚轮上/下，6/7 为 XBUTTON1/2，8..19、124..127 为手柄。码 22 为 Enter，23/24 为 Shift/Ctrl，25 为 Esc，33..36 为上/下/左/右。键盘来源是 GetKeyboardState。
- `0x140055260` 对每个绑定独立检测按住/按下/松开，再按动作求 OR。一个绑定释放、另一个仍按住时，可以同时 released/held，不能仅比较合并后的动作状态。
- `0x140054d90` 等消费函数清除 press/release、保留 held；`0x14005f700` 按钮导航消费松开并请求移动系统光标。

真实 `key.cfg` SHA-256 `001a995f6798ccbda7069e740b3123b2ed4b8869659b9828da110b44567d67b0`。动作 0 绑定 1/12/22，动作 1 绑定 3/13/25，动作 2/3 绑定 33/8 与 34/9，动作 7/8 绑定 23 与 24。配置只读，不进入 Git。

## 实现与边界

core 的 `KeyBindings` 提供 64 KiB 上限的 ASCII INI 子集；缺失项为 0，越界码归零，相关数值格式错误明确报错。`CodeInput` 保留输入码历史，向既有 `ActionInput` 提交新帧。具体窗口事件转换留在 desktop。

每次 VM 让出后的下一帧采样一次，8ms 协作预算续跑保留已消费状态。失焦清除按住、待采样事件、指针和历史，不制造释放点击。两帧之间完成的短按锁存为一个按下帧，再于下一帧释放；这是事件宿主的保留策略，不宣称复现 Windows 轮询可能漏掉短按的行为。

指针按 `RgbaImage::draw_fit` 相同的整数比例/留边映射到 1280×720；窗口外、黑边和零尺寸不映射到按钮。导航请求经同一视口转换回客户区，窗口移动系统光标；失败明确报错。

默认 native 模式必须能只读打开根目录 `key.cfg`，不猜默认键位。`--input record` 不读配置、不注入 VM。活动游戏的 Esc 交给动作绑定；暂停、素材预览或 record 模式仍可 Esc 退出，关闭按钮始终可用。

当前不读注册表覆盖，不支持手柄、第二组 51..74 绑定、配置界面或完整手势识别。导航键保留逻辑含义，包括 NumLock 关闭的小键盘；字母/OEM 键暂按物理位置，非 US 布局与原版虚拟键的一致性未验证。

## 验证与新断点

- 合成测试覆盖配置边界、多绑定 held/released、消费后历史、失焦、留边坐标、滚轮脉冲、短按锁存、左右 Ctrl 和小键盘导航语义；不含真实游戏数据。
- 仓库外探针从正常入口、种子 0、16ms 帧推进，经真实标题按钮 1 的悬停/左键按下/松开进入开始游戏分支，在第 5382 步前的表达式报错。另一个探针重放码 34 导航和码 22 确认，产生光标请求 `[641, 281]`，到达同一断点。
- Windows release 原生窗口目视检查：点击「はじめから」后标题淡出，到达同一错误。VM 错误关闭窗口，错误输出包含脚本、PC、栈长和栈顶字。
- 正常桌面权限的 100 秒有界运行：Enter 在 OP 中触发跳过，回到标题，截止正常退出；音频采用 record。自动化 Down 在此环境发为 Numpad2，未得到原生方向键导航成功的可视证据，不列为验证通过。沙箱的一次导航光标移动返回 Access is denied。

新断点：**`intproc.ps3` 表达式 PC `0x4201e`，内部操作数 PC `0x42020`、类型 `0x0106`，SP=124**，报 `operand storage/type is not implemented`。它是开始游戏分支的求值器断点，不是未知系统命令；尚未运行剧情，未知数据没有补零或跳过。
