# 场景影片：CMV6、CMV8 与 CMV9

场景影片独立于全屏 OP 生命周期，由 `MovieHost` 绑定场景对象。支持无实际音轨的 24 位 CMV6、32 位 CMV8（JBPE alpha 帧）和 24 位 CMV9（静态底图）。CMV5/7、16 位设备路径和未支持的音轨明确拒绝；播放模式及恢复布局按引擎档案选择。

格式依据来自[Amatsutsumi 样本](../games/amatsutsumi/README.md#样本身份)，其他构建的差异见各游戏档案。

## 容器

前 44 字节沿用 CMV 字段：签名、资源偏移、文件长度、保留字、最大序号、帧率分子/分母、宽、高、位深、音频标志。`max_sequence + 1` 个 20 字节索引项紧随其后，结构为序号、存储长度、解码长度、类型、资源区内偏移。只解码序号小于 max_sequence 的类型 2 项，不能把最后的保留项当作视频帧。

索引之后、资源区之前是静态数据块：u32 总长（含自身）、u16 MCU 列数/行数、`ceil(列×行/8)` 字节位图，再接底图 JBPD。位图按 256×256 纹理块、块内 MCU 行/列的顺序读取，每字节从最高位开始。位为 1 的 16×16 MCU 由底图解码，位为 0 的 MCU 由目标视频帧解码；后者以底图为背景合成。末端 MCU 可以越过名义宽高，输出裁到名义尺寸。

底图 JBPD 的表起点是 +4 字段本身，普通帧则是字段 + 4；普通帧 +44 是纹理块更新位图，独立解码不使用它跳过输出。两者沿用已有频率树、DC 差分、AC 游程、量化、整数 IDCT 与颜色转换。+36 是实际 DC 数量，必须等于本次存在的 MCU 数×6。带 bit 12 的普通帧布局表后有 u16 字节长度及复用位图；独立帧路径跨过它并解码所有动态块，不依赖前一视频帧。

所有文件/像素受既有 64 MiB 载荷上限约束，索引另限最多 2^20 项；边界、掩码、网格、DC 数量或位流不符均报错。这不是整个进程的峰值内存保证。`cmv9::Cmv9Index` 为核心入口；当前 `cmvs-cmv` CLI 仍仅接受 CMV6。

## 创建与所有权

三个影片槽绑定场景对象；资源使用独立 `SceneMovie` 注册表。创建时解码指定初始帧并建立图像和绘制状态，初始不播放。销毁播放器保留场景对象及最后图像；同槽重新绑定也不删除先前场景对象。

资源、索引和初始帧全部成功后才提交。非法槽、缺失资源、失效绑定或跨影片槽覆盖同一对象时会报错，保留待处理指令和旧状态。名称最多 63 字节，场景对象限 0..255。

| 命令 | 参数与行为 |
|---|---|
| `0x2308` | 影片槽、场景槽、名称、未读取参数、初始帧；回收 20 字节，创建后停止 |
| `0x230e` | 在上述参数后追加加载模式；回收 24 字节，仅接受已支持模式 |
| `0x2309` | 影片槽、段号、起始帧、结束帧、循环；回收 20 字节 |
| `0x230a` | 销毁播放器，保留场景图像 |
| `0x230b` / `0x230c` | 恢复 / 暂停，保留段和当前图像 |
| `0x231a` | 查询活动状态，空槽或自然结束返回 0；不推进播放器 |

## 段播放与时钟

段号为 0..15，结束帧 -1 表示最后一帧。未活动时设置当前段并激活，活动时只登记待切换段；设置段不立即跳到起始帧，也不清除暂停标志。

默认模式 0 使用独立 u32 毫秒时钟：每次时差钳到 1000 ms，累加小数时间，计算 `steps=(elapsed*rate)/1000/rate_time`，再扣除 `1000*steps*rate_time/rate`；乘积按 u32 回绕。段尾优先切待处理段，其次循环，否则清 active、置 paused 并保留末帧。单次最多 65536 个逻辑帧步，只解码最终变化目标。

暂停保留 active、当前帧和小数时间。恢复仅清 paused；若仍 active，同时重设时钟并清小数时间，不隐式启动已结束的段。已核对的 NATSUUTA 档案另支持时钟模式 15，见[游戏档案](../games/natsuuta/README.md)。

帧更新先于序列及场景效果。解码或绑定校验失败保留该槽的旧图像、帧和计时，不能重试已部分提交的状态。

## CMV6 与 CMV8

CMV6 不使用静态底图，JBPD 帧见[解码布局](jbpd-format.md)。场景索引的 decoded_size 可为 RGB 长度或加 54 字节 BMP 头长度；音频标志非零但最终音频项长度为零时仍可创建，实际非空音轨拒绝。

CMV8 使用 JBPE、32 位和带 alpha 的场景表面，复用 JBPD 的频率树、DC / AC、IDCT 及颜色转换，差异如下：

- 显式量化表为三张，共 192 字节，第三张用于 alpha；表后包含 u32 DC 总数和瓦片布局。

- 每个 MCU 依次为四个 Y、Cb、Cr、四个 alpha 块，DC 总数须等于 MCU 数×10。

- 复用位图按向上取整的 16×16 MCU 网格计算，输出裁到名义宽高。

- alpha 样本有效范围 −128..383，映射为 clamp(v,0,255)，不加 128；范围外报错。

## 验证摘要

| 输入类型 | 独立对照与运行检查 |
|---|---|
| CMV9 | 抽查四帧 RGBA 与 Python / NumPy 一致；700 项帧号和余数覆盖两次循环 |
| CMV6 场景影片 | 抽查四帧一致；135 帧播放、自然结束与保留末帧通过 |
| CMV8 | 全部 30 帧可解码，抽查七帧 RGBA 一致；段播放保留 alpha |

合成回归覆盖边界、循环、暂停 / 恢复、绑定失效及解码失败后的状态保留。对照不代表原生窗口、真实音轨或所有播放模式通过；真实资源及输出不入库。
