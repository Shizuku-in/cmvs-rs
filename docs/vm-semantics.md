# VM 表达式、参数与控制流证据

适用二进制 SHA-256：`dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5`。
本轮结论来自 IDA 静态反编译；未与原程序动态执行轨迹对照。

## 表达式编码

前缀：0x0200 整数，0x0201 字符串引用，0x0202 浮点。结束词均为 0x020f。
多数普通操作数由 16 位 tag 和 32 位数据构成；嵌套、索引与运算符有不同长度，不能固定步长扫描。

整数入口 `0x140066200`：

- 0x0100：32 位立即数；运算以有符号 32 位整数解释。
- 0x0101 / 0x0102：后接整数子表达式，分别用结果索引整数变量或位变量。
- 0x0105 / 0x0109 / 0x0110 / 0x0112 / 0x012d / 0x012f：base 后跟一个子表达式，元素步长为 4。
- 0x0107 / 0x010b：base、16 位 stride、一个子表达式。
- 0x0111 / 0x0113：base、16 位 stride、两个子表达式。
- 0x0160..0x0169：乘、除、余、加、减、与、或、异或、左移、有符号右移。
- 0x016a..0x016f：大于、大于等于、小于、小于等于、逻辑与、逻辑或。
- 0x0170：赋值；0x0171/0x0172：相等/不等。
- 0x0173..0x017e：递增、递减及复合赋值。当前只解析结构，不执行修改。

读取器 `0x1400652e0` 和写入器 `0x1400657b0` 证明这些操作数有左值/右值之分。
整数全局读写辅助函数 `0x140085e00/0x140085dc0`，位变量辅助函数 `0x140085d60/0x140085ce0`。
后两者通过字节索引与位掩码访问，不能用普通整数数组代替。
读取还会涉及变更追踪；后续 VM 不能只根据函数名忽略这些副作用。

Rust 当前只执行纯整数常量算术、比较和逻辑运算。整数加减乘使用 wrapping，移位计数按低五位处理。
除零和有符号除法溢出报错，不模拟原 CPU 异常。非法表达式栈形状和未知状态显式报错。

## 字符串引用

`0x140066b00` 生成引用；`0x14006b850` 根据高两位选择区域，低 30 位为偏移或索引：

| 高两位 | 区域 |
|---|---|
| 00 | 当前脚本文本段 |
| 01 | 当前脚本可变数据段 |
| 10 | 全局字符串槽 |
| 11 | 当前调用帧数据 |

本版字符串槽解析器按 1024 字节步长，索引大于 127 时回退到第 0 槽。
Rust 目前保留槽编号，没有在没有运行上下文时伪造指针或复制此回退行为。
浮点和字符串表达式保留原始类型与位数据，未按 UTF-8 或整数强行求值。

## 参数栈和系统返回值

主循环 `0x140067930`：0x0430 将 32 位结果寄存器压栈，SP 增加 4。
系统命令返回 16 位状态，主循环解释如下：

| 位 | 效果 |
|---|---|
| 0x8000 | 本次主循环让出执行 |
| 0x4000 | PC 前进 2，并按低 8 位的**字节数**回收栈 |
| 0x2000 | 增加重试/重复计数，否则清零该计数 |

示例：0x2000 返回 0xc000，让出执行且前进 PC，不回收参数。
0x2010、0x2011、0x2014 对应处理函数 `0x140071710/0x1400717c0/0x140071b30`：
SP-4 读取槽号，SP-8 读取字符串引用，返回 0x4008，即回收 8 字节。
0x201d/0x201e/0x201f 读取栈顶 32 位数并返回 0x4004。
0x2080 的处理函数 `0x1400810f0` 从栈顶解析脚本名，切换脚本后返回 0；不能套用普通命令的 PC/栈回收逻辑。
底层路径注册时还有当前根目录和包配置参数，覆盖优先级尚未验证。

## 控制流

- 0x0400：长度 6，后接目标 PC，绝非 NOP。
- 0x0401 / 0x0402：长度 6，依据条件标志最低位跳转。
- 0x0403：长度 10，比较立即数后决定跳转。
- 0x0407：长度 10，目标取 PC+6；PC+2 的 32 位字段在当前主循环中没有用于比较。
- 0x0405 / 0x0410：16 位标签索引；0x0410 额外压返回 PC。
- 0x0411 / 0x0412：16 位栈调整字节数，具体返回语义仍需完整执行器验证。
- 0x0440 / 0x0442：长度 8，16 位栈调整数及 32 位立即数，不等同于普通 push。

## 验证与边界

本作 start.ps3 全部代码通过 Rust 结构解码，并校验入口、标签与直接跳转目标。
完整反汇编输出只保存在仓库外 scratch 目录；合成测试覆盖类型、嵌套、后缀顺序、移位、异常算术与截断。
当前输出是线性结构，尚无可达性分析、变量状态、调用帧执行、系统后端或完整浮点语义。
