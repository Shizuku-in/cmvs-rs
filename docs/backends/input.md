# 输入

核心的 `KeyBindings` 读取 `key.cfg`，`CodeInput` 保留输入码历史，`ActionInput` 保存供脚本消费的动作状态。桌面由 `cmvs-desktop::game_input::GameInput` 转换键鼠事件；触摸适配见 `cmvs-input`，手柄策略见 `cmvs-console`。运行参数见[运行指南](../guides/running.md)。

## 配置与输入码

`key.cfg` 使用 ASCII INI，最大 64 KiB。读取 `KEY_FUNCTION_01..24` 中的 `KEY_DATA_01..05`，每个动作最多五个绑定。缺失项和越界码为零，相关数值格式错误会报错；不读取注册表覆盖和第二组绑定。

| 输入 | CMVS 码 |
|---|---|
| 鼠标左 / 中 / 右键 | 1 / 2 / 3 |
| 滚轮上 / 下 | 4 / 5 |
| 鼠标侧键 | 6 / 7 |
| Enter / Shift / Ctrl / Esc / Space | 22 / 23 / 24 / 25 / 26 |
| 上 / 下 / 左 / 右 | 33 / 34 / 35 / 36 |
| F1..F12 | 52..63 |

桌面 native 输入要求能读取游戏根目录的 `key.cfg`；`--input record` 不读绑定、不注入动作。活动游戏的 Esc 交给脚本绑定，关闭按钮始终可用。方向键保留逻辑含义，包括 NumLock 关闭的小键盘；字母和 OEM 键按物理位置映射，非 US 布局的一致性尚未验证。

## 帧与消费

每个引擎帧只采样一次输入，VM 预算耗尽后的续跑保留同一份状态。每个绑定分别检测 held / pressed / released，再按动作合并：一个绑定释放、另一个仍按住时，released 和 held 可同时成立。脚本消费边沿不会清除 held 或输入码历史。

失焦清除按住状态、待采样事件和指针历史，不制造释放点击。两帧之间完成的短按锁存为一个按下帧，再于下一帧释放。手势识别由核心按逻辑指针和帧时间推进，支持模式 0 的按键、长按与移动及模式 1 的区域拖动；未支持的模式明确报错。

## 坐标与光标

绘制、指针采样和导航定位共用 `viewport` 矩形，以运行时逻辑画布尺寸映射物理客户区。窗口外、内接黑边和零尺寸不产生游戏坐标；外接裁切按相同矩形反算。

Wayland 普通窗口不支持主动移动系统鼠标。按钮导航保留内部目标坐标，直到真实指针移动或离开游戏区域；其他平台按宿主能力定位光标，失败会报错。

光标自动隐藏由 `MOUSE_INFO/AUTO_CLEAR` 配置，提供禁用及 5/10/15/20 秒档位。核心按逻辑坐标最后变化时间计时，按钮和键盘操作不重置；离开游戏区域或失焦时，桌面恢复宿主光标。记录输入和独立素材预览不隐藏光标。

## 后台运行

`SYSTEM_INFO/ACTIVE_DRAW` 决定失焦时是否继续脚本与场景。宿主通过 `Runtime::set_focused` 报告焦点；暂停时 `tick` 返回 `Inactive`，恢复不补算暂停时间。音频服务和影片推进与脚本暂停分开，不应把此设置视为静音或停止后台影片。

合成检查覆盖绑定、边沿消费、短按、焦点及视口转换；游戏交互和原生设备的验证范围见[游戏档案](../games/README.md)。
