# 桌面后端

`cmvs-desktop` 提供窗口、键鼠输入、呈现和运行入口；游戏状态与脚本语义由 `cmvs-core` 管理。启动命令、字体、音频和用户目录配置见[运行指南](../guides/running.md)，完整参数见[CLI 指南](../guides/cli.md)。

## 服务

| 功能 | 当前实现 |
|---|---|
| 窗口与输入 | winit 窗口、焦点、标题、图标和光标；按 `key.cfg` 转换键鼠事件 |
| CPU 呈现 | 软件场景合成，经 softbuffer 显示 |
| GPU 呈现 | 可选 `wgpu-renderer`，消费同一绘制队列；见 [wgpu 后端](wgpu.md) |
| 文字 | `cmvs-font` 提供字体度量、光栅化与合成；见[字体后端](font-output.md) |
| 音频与影片 | 可选原生音频、全屏及场景影片；见[音频后端](audio-output.md) |
| 保存 | 独立用户目录中的剧情槽、系统存档和设置；正常退出保存设置，VM 错误退出不自动保存 |
| 系统对话框 | 通过 `cmvs-native` 提供字体选择、存档评论输入及 CVNS 选色 |

CVNS 选色在 Windows 使用系统对话框的两个自定义色块。Linux 使用 Zenity，macOS 使用系统选色器，两者以第一个色块为初始颜色。没有选色器的宿主按取消处理。

独立素材预览与游戏会话分开：预览不执行脚本，也不发布游戏设备帧。逻辑画布尺寸由运行时配置决定，不固定为 1280×720。

## VM 时间片与完整帧边界

桌面使用 8 ms VM 预算保持事件循环响应。预算耗尽时续跑同一次 VM，不重复采样输入、不推进场景或帧时钟，也不绘制部分执行状态；只有实际 `RuntimeEvent::Yield` 后才完成帧更新并允许合成。CPU 和 GPU 共用 `FrameDriver`，窗口在中间收到 resize / redraw 时保留上一完整画面。

即时设备帧读取返回最近一次已完成的逻辑画布，包含文字和影片，区别于脚本保留的延迟截图。`--save-frame` 也导出最后成功呈现的帧；尚无完整帧时明确失败，退出时不重绘部分 VM 状态。详见[设备帧契约](platform-host.md#即时设备帧读取)。

## 显示与输入

普通窗口按比例内接；全屏使用独立的缩放开关与比例模式。绘制、指针命中和导航坐标转换使用同一视口。全屏采用无边框窗口，不改变显示器的独占分辨率。窗口尺寸恢复、缩放和滤镜契约见[平台宿主](platform-host.md)。

Wayland 导航使用内部指针坐标；失焦、短按锁存、光标自动隐藏和后台运行策略见[输入](input.md)。

## 支持边界

不支持的脚本命令、场景模式、资源或设备请求明确报错。渲染错误附带后端、脚本位置和 VM 步数。OpenType 字形与不同图形后端不保证逐像素复刻原版。

系统依赖与平台构建见[平台总览](../../platforms/README.md)；各游戏的路线、原生交互、音轨和平台验证统一见[游戏档案](../games/README.md)。
