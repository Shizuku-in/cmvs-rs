# 字体与文字合成

`cmvs-font` 负责字体文件、名称解析、字形度量、光栅化与缓存；`cmvs-core` 负责脚本排版、换行、注音、逐字显现和等待。桌面通过 `--font <字体文件>` 启用绘制，TTC 集合可用 `--font-face <索引>` 选择，默认 0。完整命令见[运行指南](../guides/running.md)。

字体文件最大 32 MiB。`--font-face` 不能单独使用，`--font` 与 `--record-text` 互斥；后者只生成字形记录。不提供两者时保留文字输出屏障。支持 Shift-JIS、GBK 和 UTF-8，编码必须与引擎扫描、字体度量一致，见[文本编码](text-encoding.md)。

## 合成

`FontRenderer::metrics` 提供布局度量；`compose` 生成字形对象并借用场景、相机及消息窗口，随后由 `SceneComposition::prepare` 构造 CPU / GPU 共用的绘制队列。独立 `prepare_objects` 调用方还需加入可见消息窗口。

| 功能 | 当前行为 |
|---|---|
| 普通文字 | 按核心记录的位置、层次、字号和透明度绘制；支持自动换行与注音 |
| 显现 | 延迟显示、透明度渐显和左至右裁切；裁切不拉伸字形 |
| 样式 | 字号 1..128、纯色 / 纵向 / 横向 / 对角渐变、无 / 一像素 / 两像素描边 |
| 粗体 | 普通 mask 向右扩展一像素；每个字形保留创建时的字重 |
| 变换 | 有限非负缩放；文字逻辑坐标须匹配画布，或由已支持的引擎档案提供转换 |
| 辅助文本 | 生成父子字形对象，按组的层次及第二贴图遮罩合成；未知图集覆盖或变换拒绝 |

字号按 em 换算字宽和字形。字形 mask 使用 `ab_glyph` 覆盖率，回退字沿用主字体基线，带两像素留边，再进行渐变、描边和 alpha 合成。字体选择、hinting、字重和边缘像素不保证与原版 GDI 一致。

缓存按字体面及像素相关样式区分，采用 LRU，最多 512 种样式和 9 MiB RGBA 像素。淘汰后，绘制对象仍引用的像素继续有效；此预算只限制缓存保留量，不是整个后端的内存上限。单帧普通可见字形最多 512 个，辅助文本共享缓存；未知样式、非法轮廓及不支持的变换明确报错。

## 字体名称与回退

显式字体作为内置缺省面 `ＭＳ ゴシック`；其他面由 `FontLibrary` 通过 `cmvs-native` 提供的系统字体目录或平台字体服务解析。测量和绘制共用字体选择规则，所选字体缺字时按字符回退到显式默认字体；默认字体也缺字时可显示其缺字字形。

原生对话框使用 Unicode 名称。用户目录的 `font-faces/` 保存完整名称，游戏配置与存档中的固定长度字段保存稳定标识；迁移存档时需同时保留该目录。旧编码名称继续支持；映射损坏、缺失或字体无法加载时回退默认字体。

| 桌面平台 | 字体选择 |
|---|---|
| Windows | 系统字体对话框 |
| Linux | Fontconfig 与 Zenity 字体族列表，需要安装相应工具及日文字体 |
| macOS | 系统 osascript / AppKit 字体族窗口 |

取消保留当前选择；服务失败明确报错。Linux Wayland 标题栏另由 winit 的 crossfont 后端处理，与游戏文字字体选择分开。

字体、布局及缓存使用合成检查和外部字体回归；真实游戏画面及平台交互的验证范围见[游戏档案](../games/README.md)。
