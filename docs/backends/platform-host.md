# 平台宿主

`cmvs_core::platform::PlatformBackend` 提供窗口、显示、对话框和设备帧服务；`PlatformHost` 验证脚本请求后交给宿主。桌面实现见[桌面后端](desktop.md)，自定义宿主入口见[API 指南](../guides/api.md)。

`PlatformBackend::apply` 返回 `Ok` 表示请求已接受并应用到宿主状态；返回 `Err` 必须保留旧状态，供挂起指令重试。宿主事件循环可能异步落实物理窗口变化，查询应报告当时的实际状态。核心在后端成功后才提交相应 VM 状态。

## 记录模式

`RecordingBackend` 保留请求和模拟状态，不创建原生窗口。`cmvs-trace --record-platform <游戏目录>` 显式启用该模式；未启用时 trace 停在需要平台服务的请求处。记录成功不等于物理设备操作成功。

请求历史最多 4096 条，资源字节按每次请求计费、合计最多 64 MiB。文本保持所选游戏编码，原生宿主负责与系统字符串转换。

## 标题、图标与光标

| 请求 | 行为与限制 |
|---|---|
| 标题 | 保存原始标题字节；场景标题与基础标题组合，组合长度及基础标题状态检查失败时不提交 |
| 图标 | 验证 ICO 目录与载荷范围，由后端选择并解码图像 |
| 光标 | 读取已登记 CUR，保留热点和像素；重复选择不重新读取，编号 0 恢复默认 |
| 缩略图配置 | 保存尺寸与启用状态，不立即截取画面 |

平台资源通过 `DirectoryAssets` 只读读取，单个文件最多 4 MiB。路径须为有限长 ASCII 相对路径，支持正 / 反斜杠及内部重复分隔符；拒绝根路径、盘符、`.`、`..` 和解析到游戏根之外的目标。

CUR 支持单目录项、40 字节位图头及 4/8/24/32 bpp 未压缩 DIB。32 位像素任一 alpha 非零时使用 straight-alpha，否则保留 AND/XOR 合成和反色语义。 [参考与许可](../references.md)

## 即时设备帧读取

`read_device_frame` 返回最近一次完成的完整逻辑引擎画面，包含文字和影片，不包含窗口边框、物理光标或素材预览。读取不消费帧，不重绘当前 VM 状态，也不借用脚本保留的延迟截图。无完成帧或读取失败时明确报错，保留挂起指令及旧图像。

需要异步回读设备帧的宿主（如 WebGPU）可覆盖 `poll_device_frame`，在读回尚未完成时返回 `DeviceFrameResult::Pending`。核心返回 `RuntimeEvent::DeviceFramePending`，保持当前指令与参数挂起且不计入让出看门狗计数，待宿主填好帧后继续恢复执行。

桌面仅在成功呈现游戏帧后发布逻辑画布。记录后端由调用方通过 `present_frame` 提供已完成的画面，默认无帧可读。软件 32 位读回将 alpha 置为 255。

## 显示与窗口

| 设置 | 宿主契约 |
|---|---|
| 全屏 | 查询当前状态；桌面使用无边框全屏，不改变独占分辨率 |
| 比例模式 | 0 原尺寸（放不下时内接）、1 等比内接、2 等比外接裁切、3 拉伸；脚本越界值归 1 |
| 全屏缩放开关 | 与比例模式分别保存；关闭时按原尺寸呈现，普通窗口仍内接；已支持的旧构建可选择左上角原点 |
| 窗口大小初始化 | 可调整且尺寸不符时恢复逻辑画布大小；全屏时只更新未来窗口尺寸，退出全屏后恢复 |
| 绘制模式 | 0 点采样、1 双线性、2 Keys 双三次、3 Lanczos4；桌面支持四档，能力不足回退 0 |

绘制、指针和导航定位共用 `viewport` 的定点目标矩形。外接裁切使用有符号偏移，空尺寸或非法缩放结果会报错。双线性和高品质滤镜在预乘 alpha 上插值，结果可能与原版图形设备有像素级差异。

显示偏好和绘制滤镜的持久化见[桌面后端](desktop.md#设置保存)。未来窗口尺寸只在当前会话内保留；具体命令的参数、让出与返回标志见各游戏的语义记录。

## 对话框

CVNS 的退出确认、脚本消息和取色使用共用的游戏内弹窗。脚本等待玩家操作，退出确认默认选中取消。

`poll_text_dialog` / `poll_font_dialog` 可返回 `Pending`，供移动端在处理事件和生命周期后继续；同步宿主可实现 `choose_font`。取消与失败分开报告。记录后端使用预置答案，没有答案时明确报错。

文本请求及字体结果遵守游戏编码和字段容量。桌面字体名称的 Unicode 映射由字体库处理，见[字体后端](font-output.md#字体名称与回退)。平台对话框及依赖见[运行指南](../guides/running.md#系统对话框)。
