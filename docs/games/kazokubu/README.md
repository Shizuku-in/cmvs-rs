## 构建与快照接入（2026-11-03）

两架构 PE 时间戳为 `0x4f59b753`（x64）和 `0x4f59b7a1`（x86），相差 78 秒；各有 864 项分派、620 个处理命令与 244 个空操作，处理命令均保留 `Unreviewed`。x64 switch `0x1400770a0`、分派表 `0x14007940c`；x86 表 `0x46497c`。游戏 ID `0x17500003` 来自 `start.ps2 / 0x201d` 的常量实参；画布配置为 1280×720。地址均绑定上表对应架构的 SHA-256。

独立只读核对 x64 快照写入/读取链，复用已有文字 v2、场景 v3 编解码；仅对本 profile 与已核对的 x64 哈希开放：

`0x22a5 → 0x140073d90 → 0x140039480` 独立核对为粒子创建，绑定现有 `particles` 变体：SP−4 槽号、SP−8 名称、SP−12 起六个创建参数，回收 32 字节，槽号超出 0–3 忽略；辅助函数 `0x1400441f0` 加载图像、`0x140044e50` 初始化参数与时钟。快照只开放该效果类型；其他效果、按钮列表和 ≥512 的嵌套子槽仍显式拒绝。该布局保存创建参数，不保存逐粒子的瞬时位置。

原始证据位于 `local/kazokubu/{native,snapshot,particle}-evidence.json`。合成回归复用现有存读档夹具，覆盖文字/场景/粒子、局部变量、备份槽及坏记录的事务性拒绝。

## 运行验证（2026-11-03）

固定种子 0、16ms 虚拟帧、鼠标和日文字体，复制原有 `system.dat` 到各次探针的隔离用户目录；原游戏只读。研究放行未复核命令不提升其语义证据等级。

- `probe-baseline`：96 个脚本、3,236,456 个静态指令、369 种系统命令结构通过；标题 `menu.ps2` 的 4 个按钮、18,748 步/624 帧到达和启动确定性通过。
- `probe-scenario`：I1–I5、P3、C1/C2 通过；当时尚未绑定快照，R2 在 1,049,905 步停止于需要快照的路径，不能视为路线通过。
- S4 初次 15 个失败均为外置 CMV9：探针的封包资源分支已有 CMV9 校验，而外置文件分支遗漏。已统一到现有 CMV9 解析器并保留载荷上限；这不是新增影片解码格式。
- `probe-snapshot-route`：修复后的 S4/L0（26,971 项资源）及剧情开头 V1–V4/L1 全部通过。首选链 `0.0.0.0.0` 经过 5 个选择点、184,678,871 步/87,071 帧回标题，按钮从 4 个增为 5 个；还有 6 个选择前缀，R2 为 inconclusive。R3 覆盖 33/96 个脚本、416,434 个静态位置（约 12.8%），不代表剧情完成度。
- `probe-snapshot-input`：默认快照下 D2/D3、I1/I4/I5 通过；P1 发现 27 个页面状态、80 次尝试、重放分歧 0，预算截断，不能认领完整页面遍历。
- `probe-final-route`：绑定 512 子槽后复跑同一首选链，步数、帧数、回标题及覆盖率均与前次一致；summary SHA-256 `c4aaa2139e56692550064cf1b6202058beaf9edc9fe30c60fdd40d21feb41e76`。最后补齐越界创建的无符号忽略行为并重建后，`probe-final-saves` 的 I5/L0 与 V1–V4/L1 再次通过；越界分支另由合成边界回归验证。
- `desktop-start.log`：CPU 窗口、默认快照、原生音频启动运行 8 秒，15,500 步正常退出，后端提交 44.1kHz 双声道标题 BGM；未做听感验收。`scenario-frame/frame.png` 抽查第 6 个消息等待的气泡文字位于框内；不代表原版像素一致。

本轮验证通过 profile/变体、runner 存读档、快照布局、子槽边界及 probe 回归，严格 Clippy、格式和差异检查；桌面含音频功能构建成功。未进行全分支、全 workspace/其他平台、原版存档互操作或原生手动全程验证。

运行时需使用独立用户目录；音频需启用 `audio-output` 并选择 `--audio native`。剧情快照默认启用。

```bash
cargo run --offline --release --features desktop,audio-output --bin cmvs-desktop -- "<游戏目录>" --encoding shift-jis --font "<日文字体>" --user-data-dir "<独立用户目录>" --audio native
```
