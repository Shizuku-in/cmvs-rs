## 图像缓存与换图

保留上方锚点供已登记映射引用。两侧图像管理器指针均在 VM `+0x1298`，下一次读取提示在目标管理器 `+0x58b8`、基准 `+0x60d8`。`0x203f` 无参数、无结果写入，设置提示并返回 `0x4000`；原始读取先读并清提示，再决定是否查缓存，递归完成后提交外层原始字节。

`0x2032` 读取对象及名称但回收 12 字节，未读取的第三字也必须回收；`0x22c4` 保留加载、旧 / 新图像、失败及有序副作用。管理器字段移动不能消除资源读取或提交顺序差异。映射假定管理器已成功初始化，原版空指针失败不属于已证明路径。

## 快照布局

本构建选择 `TextV2`。文字记录依次为 u16 版本 2、容量、NUL 字体名、两个逻辑尺寸、156 / 148 字节公共块、字形数和每项 44 字节描述；无基准 v3 的 208 字节禁则块。恢复重建字形并将画笔放回区域原点。

窗口 / 场景 / 图像使用已支持的公共记录子集。特殊图像、活动效果和未知派生布局仍拒绝，命令复核不覆盖这些磁盘差异。存档捕获、安装与公共备份规则见[快照格式](../../formats/snapshot-format.md)。
