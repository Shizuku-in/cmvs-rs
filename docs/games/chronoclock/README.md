# 《クロノクロック》测试档案

2026-10-30建档，基线`6475d2f`。截至2026-10-31，档案登记455条`Inherited`、167条`Presumed`、22条`Reviewed`、68条`Unreviewed`及264条`NoOp`；x86独立报告425条继承、207条推定，未直接合并。文字/窗口组新增九条复核后，默认闸门的无快照runner在steps=93397、`cdemo.ps3 / 0x2105e / 0x203f`明确报未复核；本轮实际执行新增命令中的3种。`0x2118`、`0x2176`虽然静态复核一致，Rust尚无处理器；复核不表示全部已实现。trace工具缺少MessageHost，旧`0x2141`属于工具处理能力屏障。剧情快照子记录存在实际构建差异，派生档案生成/恢复快照仍显式拒绝。先前研究放行下runner的`0x2112`停点保留为历史记录。见[研究记录](research.md)、[VM语义](vm-semantics.md)及[指纹报告](profiles/)。

## 系统命令分派（本作二进制）

系统命令由 `0x14007ea60` 中的 switch 分派：`movzx eax, dx` 取低 16 位作为 case，共 976 项，跳转表 RVA 数组在 `0x140081344`，越界命令落到 default `0x14007eaba`（返回 0）；范围内另有 264 个 case 指向共用的空操作存根 `0x14007eaa7`（`mov eax, 4000h` 后返回，无副作用）。建档初稿把这个存根误记为 default，2026-10-30 实现引擎档案时更正。用 IDA 抽查的映射如下：

| 命令 | 处理函数 | 备注 |
|---|---|---|
| `0x20d4` | `0x140071420` | 调用 `rand`，与《アマツツミ》随机数命令同号，细节未逐条复核 |
| `0x2080` | `0x14007d7b0` | 未复核 |
| `0x22b3` | `0x1400791b0` | 未复核 |
| `0x2026` | `0x140068aa0` | 见下文 |
| `0x2112` / `0x2119` | `0x14006f930` / `0x14006f9f0` | 文字布局测量尚未实现 / 显示字节计数已实现，见VM语义 |
| `0x22ca` / `0x22ff` | `0x1400782d0` / `0x140078400` | 未分析 |
| `0x211e` / `0x211f` | 空操作存根 `0x14007eaa7` | 本作只返回 0x4000；《アマツツミ》中是真实处理函数，不能套用其语义 |

### 0x2026 建档时的初步证据

`0x140068aa0`：栈参数从 SP 往下依次是 `[SP-4]` 对象槽、`[SP-8]` 子对象号、`[SP-12]` 标志。

- 对象槽小于 256 且该槽非空时：子对象号 ≥ 0 就用 `0x140038b60` 取子对象（下标不小于 `0x300` 时得到 NULL），否则直接用对象本身；然后 `0x140038b00` 把 `标志 != 0` 写入对象的 `+0x1864` 字段。
- 对象槽越界或为空时，给 VM 状态 `+0x2f18` 置位 `0x10`，不写字段。
- 两条路径都返回 `0x400c`。子对象号合法但该子对象为 NULL 时，原版会写空指针，结果未定义。
- `+0x1864` 在 `0x1400387d0` 中初始化为 1，只被 `0x140038af0` 读取；它的唯一调用者 `0x14003bfe0` 在该值为 0 时跳过节点。因此**推测**这是绘制可见性开关，尚未通过画面验证。
- 以上为建档时结论。2026-10-31 已核对基准构建对应完整处理函数，并复用对象 `shown` 实现正常目标分支及 `0x400c` 清栈；非法/缺失目标仍明确报错。当前证据及测试见 [VM 语义](vm-semantics.md)。

## 重现与限制

- 测试日期 2026-10-30，代码 `6475d2f`，release 构建。游戏目录保持只读；输出放在忽略的 `local/chronoclock/initial/`。
- 结构检查：照搬《アマツツミ》[脚本审计](../amatsutsumi/script-audit.md#重复运行)的命令，把 `CMVS_SCRIPT_TEST_INPUTS` 换成本作的 `script.cpz;start.ps3`。报告 SHA-256 `b75f9d6e2004728bc05e4a72df66c1df141865231995b074341b544ededb4b57`。
- 启动 trace：`cmvs-trace <游戏目录>/data/pack/start.ps3 --bootstrap --save-dir <游戏目录>/save --system-save <游戏目录>/save/system.dat --script-archive <游戏目录>/data/pack/script.cpz --record-platform <游戏目录> --continue-without-snapshot --frame-ms 16 --rand-seed 0 --steps 1000000`。日志 SHA-256 `3904db2db18cc939ccbe9bb8e44ba8047cc79a51f381a2f4fba920d84247ad30`。不加 `--save-dir` 会停在 `start.ps3 / 0x22b3`，不加 `--rand-seed` 会停在 `logo.ps3 / 0x20d4`，两处都和《アマツツミ》行为一致。
- P1时本作档案`cmvs-20150405`（基准`cmvs-20160201`）的712条处理命令全部为`Unreviewed`；P2已将其中387条以完整x64指纹登记为`Inherited`。264条`NoOp`不变。游戏ID`0x17700011`、原二进制与case身份均保持，见[引擎档案设计第13节](../../design/engine-profiles.md#13-p2-实施与使用2026-10-31)。

- P3（2026-10-31）：`0x2091`的处理函数、位写入及错误标志指针绑定经人工复核，登记为`Reviewed`；默认trace停点前移到`start.ps3 / 0x76 / 0x2092`。
