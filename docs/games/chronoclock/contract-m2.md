## 全局字段

字段按写入、重置及查询角色配对，表中均为 32 位全局单元，位置为各自 exe 的 RVA。映射文件与其他规则见[上下文](contract-context.json)、[映射](contract-mappings.json)及[摘要](contract-summaries.json)，规则哈希由运行时重算。

| 逻辑字段 | 基准 RVA | 目标 RVA | 交叉证据 |
|---|---|---|---|
| `clock.current_tick` | `0x101430` | `0xfb3d0` | 重置把时钟源结果写入此字；`0x2008` 模式0读它，`0x2009` 用它减前一时刻 |
| `clock.previous_tick` | `0x10142c` | `0xfb3cc` | 重置写与当前时刻相同的值；增量查询的减数 |
| `clock.accumulated_tick` | `0x101434` | `0xfb3d4` | 重置清零；模式非零的时刻查询读它 |
| `clock.frame_delta` | `0x1013f8` | `0xfb398` | 重置清零；模式非零的增量查询读它 |
| `clock.mode` | `0x101438` | `0xfb3d8` | 模式 setter 保存 `ecx` 后重置上述四字；两个查询均用它与0比较 |
| `button_layout.shifted_layout` | `0x101448` | `0xfb3e8` | `0x2087` 写参数非零归一化值；getter 供按钮状态布局函数读取 |

时钟重置函数为基准 `0x140008cb0` / 目标 `0x140007ca0`，模式 setter 为 `0x140008cf0` / `0x140007ce0`；重置写入相同的当前 / 前一时刻并清累计 / delta。布局 setter 为 `0x140008060` / `0x140007050`，getter 为 `0x140008070` / `0x140007060`，消费者为按钮布局函数。两侧字段位于可写节的零填充尾部，不以 IDA 显示残值证明初值。

## 接受命令

| 命令 | 契约 |
|---|---|
| `0x2008` | 模式 0 读当前时刻，否则累计时刻；结果 0，返回 `0x4000`，不回收参数；保留条件移动的三次内存读取 |
| `0x2009` | 模式 0 用 32 位当前减前一时刻，否则帧 delta；结果 0，返回 `0x4000`；只读所走分支 |
| `0x2087` | 读取 SP−4，保存 `arg != 0`，返回 `0x4004`，回收 4 字节；负值也归为 1 |

完整符号契约及原 exe 字节绑定一致，并用独立公式检查共享输入、回绕、读取顺序和副作用。反转条件、替换字段、修改运算或回收量均应判不同；未映射写入应保持未知。这三项不证明外部时钟源或按钮布局消费者本身等价。
