## 构建差异

差异只绑定本页 x86 哈希，539 个处理命令保持 `Unreviewed`。

| 范围 | 兼容规则 |
|---|---|
| 画布 / 子槽 | 旧配置选择 800×600，文字、命中和抓图共用尺寸；子对象表 256 项 |
| `0x204e` | 父槽、子槽和模式，负子槽取本体，模式归一为 0 / 1，回收 12 字节；非法目标报错 |
| `0x22a5` | 类型 5 独立粒子池，每粒子初始化 8 次、重生 2 次共享随机数，位移 delta 上限 500 ms；x87 用 f64 与已核对 f32 落栈点模拟 |
| 输入查询 | `0x219c` / `0x219e`、`0x21a0`–`0x21bc`、`0x22f0`–`0x22f5`：结果 0 为按下边沿、结果 4 为 held；配套命令只消费边沿 |
| `0x231b` | 设置场景影片当前帧；不混同分段播放和活动状态 |
| `0x21fa` | 旧版世界轨道及正弦模式，保留构建专属算术和快照进度 |
| 场景影片 | 支持模式 0 / 10，10 只推进当前段，不应用 pending 或 loop；模式 15 拒绝，未支持控制状态读回拒绝 |
| `0x20b8` | SE 独立倍率 /256，更新不重启声音；不是速率。非默认倍率的存档恢复拒绝 |
| `0x20b4` | 从头重播已准备 SE，保留独立倍率及循环状态 |
| `0x213c` / `0x22bc` | 存档评论对话框与元数据更新，原版区分确认、取消、空值回退和全角过滤 |
| 投影 / 震动 | 支持已核对的旋转投影子节点和水平 / 垂直三角波；保留周期相位快照，零周期和随机震动拒绝 |

### 旧版快照

文字 v1、窗口 v1、场景 v2、图像 v3、绘制 v4；场景对象头八字，包含旧正弦轨道。相机 v3、视图 v2、场景影片 v4 为 298 字节。按钮读回恢复为空组，类型 5 的 60 字节记录仅存创建参数，恢复重新消耗共享随机数，不保存瞬时位置。

CSS1 偏移 68 固定零，未推断作品 ID。旧 mask、按钮列表、其他未核对效果及非默认 SE 倍率恢复继续拒绝；公共记录格式见[快照说明](../../formats/snapshot-format.md)。

## 验证条件

自动检查使用种子 0、16 ms、鼠标、日文字体及独立用户目录，游戏只读。无窗口重放、算法对照、原生设备和物理交互分别统计；未复核命令的运行放行不提高证据等级。原版存档互操作、任意保存点及其他平台未完整验证。

## 运行

使用[桌面运行](../../guides/running.md#桌面运行)，选择 Shift-JIS、默认快照及独立用户目录。探针需完整画面时加 `--render-frames`，以完成帧提供设备抓图；未生成画面时抓图明确失败。
