# 按钮布局契约依据

本页由已登记的契约映射引用，仅保留字段角色。基准为 `cmvs-20160201`，x64 SHA-256 `dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5`，image base `0x140000000`。游戏验证见[档案](README.md)，命令规则见[基准契约](vm-semantics.md)。

| 范围 | 已核对关系 |
|---|---|
| `0x2087` | setter `0x140008060` 将参数非零归为 1，写全局 `0x140101448`；getter `0x140008070` 读取同一字 |
| `0x2214` / `0x2215` | 按钮布局 / 状态绘制消费该标志；状态记录由子对象号、裁切和原点构成 |
| 按钮组 | VM `+4504` 的 6 个组绑定场景对象，节点保存 ID、启用、矩形、导航及四种状态 |
| 初值 | 全局字段位于磁盘 `.data` 之外的加载器零填充尾部；IDA 显示的 `ffffffff` 不作为初值证据 |

该字段配对只证明写入 / 查询角色，不证明布局消费者整体等价；登记流程与限制见[契约表](../chronoclock/contract-m2.md)。
