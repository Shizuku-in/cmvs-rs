# 基准命令契约

适用 `cmvs-20160201`，x64 `cmvs64.exe` SHA-256 `dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5`，image base `0x140000000`。游戏支持和验证见[档案](README.md)。本页保留公共 VM 规则及契约映射需要的字段，精确命令实现以 core 为准，不维护历史断点和本地导出。

## 表达式与引用

| 范围 | 契约 |
|---|---|
| 表达式 | `0x0200` 整数、`0x0201` 字符串引用、`0x0202` 浮点，以 `0x020f` 结束；操作数长度按类型解码，不固定步长 |
| 整数 | i32 wrapping 加减乘，移位取低五位；除零、除法溢出、非法栈形状和未知存储报错 |
| 字符串引用 | 高两位区分脚本文本、可变数据、全局字符串、调用帧；低 30 位为索引 / 偏移，不暴露主机指针 |
| 浮点 | 系统浮点结果保留原始位；不同构建的 x87 / SSE 运算按已核对分支选择 |

实现见 `bytecode`、`evaluate`、`vm` 和 `machine`，文本扫描规则见[文本编码](../../backends/text-encoding.md)。

## 调用与帧边界

| 返回位 | 效果 |
|---|---|
| `0x8000` | 让出本次 VM 运行 |
| `0x4000` | PC 前进 2，按低 8 位的字节数回收参数 |
| `0x2000` | 增加重复计数，否则清零 |

系统参数按 SP−4、SP−8 等字节偏移读取，已忽略参数也计入回收。脚本切换和公共调用使用独立的控制流路径，不能套用普通完成规则。预算耗尽不等于让出，只有完整帧更新后才采新输入或合成，见[帧边界](../../backends/desktop.md#vm-时间片与完整帧边界)。

## 契约字段

以下只用于绑定原构建与离线模型，不作为宿主 API。VM 错误字为 `+12056`，对象 / SE / 文字 / 窗口错误位分别包含 `0x10` / `0x200` / `0x1000` / `0x10000`；Rust 对非法索引或缺失状态返回错误，不复制越界或空指针行为。

| 字段 | 基准位置及用途 |
|---|---|
| 系统结果 | 快照 `0x248`，VM `+82816..+82856` 共 11 字；运行时按已实现的整数 / 浮点槽解释 |
| 场景表 | VM `+1976`，256 项；命令不得将非法索引当作成功 |
| 消息窗口 / 文字表 | VM `+4064` 的 8 个窗口、`+4128` 的 12 个文字对象 |
| 图像管理器 | VM `+0x1298`；`0x203f` 写管理器 `+0x60d8` 的下一次读取缓存提示，原始读取先消费再查缓存 |
| 文字前缀 | `+8..+163`、`+176..+323`；现代构建另有 `+328` 起 208 字节扩展块 |
| 布局模式 | `0x2087` 将非零参数归为 1，供按钮状态布局读取 |
| 时钟 | `0x2008` 按模式读取当前 / 累计时间；`0x2009` 读取当前减前一时刻 / 帧 delta，均写结果 0 |

构建对字段配对及证书边界见[Chronoclock 契约](../chronoclock/contract-m2.md)。

## 场景、相机与效果

| 命令 / 范围 | 行为与边界 |
|---|---|
| 图像 / 绘制 | 资源先完成读取和解码再提交；坐标、源矩形、层次、缩放、旋转和透明度由共享绘制队列消费 |
| `0x2078` | 查询对象 / 子对象 XYZ 原始位，写浮点结果 8..10 |
| `0x2260`–`0x2264` | 独立 3D 视图状态及快照；不等于普通模式 1 的完整呈现支持 |
| `0x2287` / `0x2289` | 序列相机 / 世界 XYZ 运动；零时长或快进使用已核对的目标写入规则 |
| `0x22a2` | 四槽类型 2 下落 billboard，每粒子创建消耗 4 次共享随机数，更新 delta 上限 500 ms |
| `0x22a8` | 类型 8 碎片接管源对象；网格按宽高向上除 20，每片 4 次随机数，7500 ms 缩小 |
| `0x22ae` | 类型 8 活动 / 完成返回 0 / −1，其他已核对类型走默认 −1；空槽拒绝 |
| `0x2328` | 模式 1 行波与模式 16 多重残影，使用独立子链；重复调用追加，保存参数后恢复重建，不保留累计时间 |
| `0x2329` | 清独立效果链，保留普通子槽、父图像和绘制状态 |
| 渲染 | 父子继承、投影、转场、混合和遮罩统一准备；未知模式及非有限参数拒绝 |

图像格式见 [PB3](../../formats/pb3-format.md)，影片见[场景影片](../../formats/cmv9-format.md)，公共呈现契约见 [wgpu](../../backends/wgpu.md)。

## 文字、输入与设置

| 范围 | 行为与边界 |
|---|---|
| `0x2152` / `0x2154` / `0x2157` / `0x2158` | 渐显、即时、追加渐显及独立自动等待；字形样式与计时由核心保存 |
| 字形 | 换行、注音、禁则、辅助图集、粗体和显现模式由消息模型处理；字体后端只负责度量及绘制 |
| 输入 | 每个完整帧采样一次，绑定分别算边沿再合并，消费边沿不清 held；手势使用逻辑坐标 |
| 回看 / 按钮 / 列表 | 保留各自状态、命中、导航与消费顺序；自然调用与受控调用的验证范围见游戏档案 |
| 音频 / 平台 | 参数通过后端契约提交，失败明确报告；窗口、显示及字体名称与原版内存布局分开 |

细节统一见[输入](../../backends/input.md)、[字体](../../backends/font-output.md)、[音频](../../backends/audio-output.md)和[平台宿主](../../backends/platform-host.md)，不在游戏证据页重复维护。

## 存档与生命周期

默认在 `0x2080` / `0x22b2` 捕获快照；复制位区时副本 bit0 为 1，实时状态结束后清零。`0x22b2` 保存位置指向下一条指令且重复计数为零。研究用无镜像模式不生成可保存字节，后续写槽明确失败。

`0x22b6` 写槽、`0x22b5` 安装完整状态，使用独立用户目录和备份；`0x228c` 交换槽，`0x228e` 移槽，保留已核对的同槽和失败续做行为。显示中字形、匿名内存图像、活动换图、旋转轨道及效果各按对应恢复规则处理，见 [CSV2](../../formats/save-format.md)、[CSS1](../../formats/system-save-format.md)和[快照格式](../../formats/snapshot-format.md)。

`0x2001` 结束会话；`0x2003` 清理运行对象、当前快照与临时状态后重新进入主脚本，保留设置、持久变量和公共回调归属。未知状态、未支持记录及后端失败不能被当作成功跳过。
