## 当前能力

本作88个脚本来源中的431种系统命令均有处理入口。下落粒子、图像碎片、效果查询及对象波形/残影已实现，`0x2328` 支持模式1和16。普通三维模式 1 及未核对模式的呈现仍明确拒绝。

截图和缩略图的匿名内存图像只保存尺寸与元数据，读档重建为不透明黑图；显示中字形按保存描述完整重绘。旋转轨道保存并恢复播放进度，特殊效果按原版规则重建，详情见[VM语义](vm-semantics.md)。

Windows已实测字体选择、光标自动隐藏和部分窗口交互。Linux Wayland已用Noto CJK及原生音频从独立用户目录启动至标题并正常退出。wgpu的Windows Vulkan/DX12合成检查及部分真实场景与CPU对照通过。

## 使用与限制

桌面配置见[运行指南](../../guides/running.md)。默认构建剧情快照；系统存档和剧情槽写入需要 `--user-data-dir`，已记录自动恢复状态的用户目录启动时会恢复相应槽。原游戏目录保持只读。

## 验证条件

无窗口路线使用固定种子、虚拟帧时间和合成输入，原游戏只读，保存使用独立用户目录。不同检查可能使用不同快照策略；不建快照的旧预览结果不用于认领存档能力。原生窗口、音频设备消费、离屏画面和受控原库调用分别统计。

## 覆盖采样

固定路线采集基线为 `89e1d50`，种子 0、16 ms、无窗口记录输入；五结局与 OP 返回标题。88 个来源共 2957772 个静态指令地址，路线触达 86 个来源、1057150 个去重地址（35.74%）及 268 / 431 种系统命令。包内、包外同名启动脚本分开统计。

这组地址覆盖不表示条件边或剧情完成度，也不增加原生音轨及画面验证范围。五路线存读档另比较 119996 个快照、11998 次读回；混合输入下的换图及匿名内存图像也有专项恢复检查。

GPU 在 Windows Vulkan / DX12 上抽查 40 个完整场景，CPU / GPU 最大通道差不超过 2；Linux Wayland 的新用户目录启动、系统保存及重启通过。原生完整流程仍以本页验证表为准。
