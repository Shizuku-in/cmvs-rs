截至 2026-10-31，当前研究对象为用户提供的 PC x86-64 样本；发行版本及补丁号未确认，不据此宣称覆盖其他发行版、汉化版或 Android 包。

## 使用与待办

审计剩余 21 条命令已完成 17 条语义与合成回归，当前还剩 4 条；已完成项覆盖即时设备截图、消息输出/等待、对象 XYZ 查询与子对象清理、纹理减法、全屏缩放开关、存档槽整理、独立三维视图状态及相机/XYZ 序列动作。这十七条尚未作真实可达站点重放，三维模式 1 呈现仍不支持。详情及高成本后置项见[推进表](semantics-progress.md)。下文完整设置重置/放弃指设置页功能，与 `0x2003` 引擎 RESET 分开。

桌面配置见[运行指南](../../guides/running.md)。默认构建存档快照；系统存档与剧情槽写入需要 `--user-data-dir`，本机系统存档记录自动读档时启动即恢复对应槽。

2026-10-31 完成度盘点：盘点时语料中 431 种系统命令里 23 种没有任何处理入口；现已接入其中退出 `0x2001` 与重置 `0x2003`，另补齐 17 条截图/消息/场景/存档/显示/视图/序列命令后，尚余 4 种缺少入口，另有已有入口内的显式屏障，清单与建议顺序见[脚本审计](script-audit.md#完成度盘点2026-10-31)。近期优先继续其余文字、角色与系统设置。标题/工具栏入口、三页切换、音频配置及初始化、窗口大小初始化/绘制模式（点采样与线性缩放）/背景动画开关与文字窗口透明度/后台运行策略/四种比例模式/窗口与全屏切换/光标自动隐藏五档/粗体/描边/文字速度/未读停止策略/语音停止方式点击、角色页音量/渐变/调色板/初始化及其对剧情语音音量与对话字色的影响、音声再生速度（0x20af与原版语音时间压缩，见[速度记录](research.md#音声再生速度与语音时间压缩2026-10-31)）、444帧设置页呈现和右键返回已验证（绘制模式见[滤镜记录](research.md#系统页绘制模式与缩放滤镜2026-10-31)，角色页见[角色设置记录](research.md#角色设置页2026-10-31)）；自动送页参数修改、开启后推进三条历史并执行三次语音淡出、关闭后240帧不再推进通过记录重放，见[语音停止记录](research.md#语音停止设置与淡出运行2026-10-31)。文字显现与已读跳过策略有合成覆盖，横向展开有外部字体像素检查；原生合成音频的增益调整、SE恢复/失败回滚、语音压低BGM及是否计入淡出语音已有设备检查。「その他設定」的「フォント選択」经0x213d打开宿主字体对话框：Windows已用ChooseFontW实现并按名称在系统字体目录解析字体（记录后端回归通过，Windows原生对话框已由用户手动实测），其他平台预留接口。设置页滑块由离散步进按钮组成，拖动不改值（与原版按钮语义一致，已回归），喇叭图标为开关而非试听。完整重置/放弃、未实现项的持久化、停止模式0/1的完整有声时机、更多有声自动送页场景和原生窗口操作仍待完成。随后完成鉴赏各页更多选项、其余回想及原生交互验证，补测未覆盖分支、原生完整路线和音轨，在原生窗口实测游戏内存读档界面与回看，字形快照及0x6a0资源记录已接入（详见下节），无 CSS1 模板首次保存已接入，真实首次启动/保存/重启待验证。自动恢复策略中的游戏 ID 检查不能直接推广到其他作品。

原生音频下已复用上述设置页回归，并自动运行到首条真实语音及其后续消息，关闭后停在文字等待；这是无窗口呈现与合成输入下的设备检查，详见[原生回归](research.md#原生音频下的设置与自动送页回归2026-10-31)。
