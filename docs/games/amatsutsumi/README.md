# 《アマツツミ》测试档案

截至 2026-10-31，当前研究对象为用户提供的 PC x86-64 样本；发行版本及补丁号未确认，不据此宣称覆盖其他发行版、汉化版或 Android 包。

## 样本身份

| 字段 | 已确认内容 |
|---|---|
| 游戏标识 | `amatsutsumi` |
| 可执行文件 | `cmvs64.exe`，x86-64，image base `0x140000000` |
| 二进制 SHA-256 | `dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5` |
| 当前编码配置 | 显式 `shift-jis` |
| 样本格式 | PS2A、CPZ6 模式 1、PB3、CMV6/8/9、CSV2、CSS1 的已核对分支 |
| 引擎档案 | 根档案 `cmvs-20160201`：x64 与同构建的 `cmvs32.exe`（SHA-256 `8b09e6b23e0eeaecccf6a584cb94720d239c00f177ed02036ab8845120d99197`）；721 个处理函数为 `base`，255 个为空操作。游戏 ID `0x17800016`，`--skip-auto-resume` 策略变量 2198 登记于游戏记录 |

本地路径仅为复现示例，不是身份依据。各脚本、资源、系统存档和音频 DLL 的哈希及验证条件见[研究记录](research.md)、[VM 语义](vm-semantics.md)和[覆盖报告](script-coverage.md)。本文所有原版地址只对上表二进制有效。

## 使用与待办

桌面配置见[运行指南](../../guides/running.md)。默认构建存档快照；系统存档与剧情槽写入需要 `--user-data-dir`，本机系统存档记录自动读档时启动即恢复对应槽。

近期优先继续其余文字、角色与系统设置。标题/工具栏入口、三页切换、音频配置及初始化、窗口大小初始化/绘制模式（点采样与线性缩放）/背景动画开关与文字窗口透明度/后台运行策略/四种比例模式/窗口与全屏切换/光标自动隐藏五档/粗体/描边/文字速度/未读停止策略/语音停止方式点击、角色页音量/渐变/调色板/初始化及其对剧情语音音量与对话字色的影响、音声再生速度（0x20af与原版语音时间压缩，见[速度记录](research.md#音声再生速度与语音时间压缩2026-10-31)）、444帧设置页呈现和右键返回已验证（绘制模式见[滤镜记录](research.md#系统页绘制模式与缩放滤镜2026-10-31)，角色页见[角色设置记录](research.md#角色设置页2026-10-31)）；自动送页参数修改、开启后推进三条历史并执行三次语音淡出、关闭后240帧不再推进通过记录重放，见[语音停止记录](research.md#语音停止设置与淡出运行2026-10-31)。文字显现与已读跳过策略有合成覆盖，横向展开有外部字体像素检查；原生合成音频的增益调整、SE恢复/失败回滚、语音压低BGM及是否计入淡出语音已有设备检查。原版字体枚举属于Win32菜单对话框，游戏内设置页只读取字体名，非当前字体的设置仍显式报错。其他页参数、拖动/试听、完整重置/放弃、未实现项的持久化、停止模式0/1的完整有声时机、更多有声自动送页场景和原生窗口操作仍待完成。随后完成鉴赏各页更多选项、其余回想及原生交互验证，补测未覆盖分支、原生完整路线和音轨，在原生窗口实测游戏内存读档界面与回看，补齐字形与覆盖层的存档记录，并处理无 CSS1 模板首次保存。自动恢复策略中的游戏 ID 检查不能直接推广到其他作品。

原生音频下已复用上述设置页回归，并自动运行到首条真实语音及其后续消息，关闭后停在文字等待；这是无窗口呈现与合成输入下的设备检查，详见[原生回归](research.md#原生音频下的设置与自动送页回归2026-10-31)。
