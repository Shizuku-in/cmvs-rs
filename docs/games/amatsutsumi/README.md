## 当前能力

本作88个脚本来源中的431种系统命令均有处理入口。下落粒子、图像碎片、效果查询及对象波形/残影已实现，`0x2328` 支持模式1和16。详见[命令实现与验证](semantics-progress.md)。

截图和缩略图的匿名内存图像只保存尺寸与元数据，读档重建为不透明黑图；显示中字形按保存描述完整重绘。旋转轨道保存并恢复播放进度，特殊效果按原版规则重建，详情见[VM语义](vm-semantics.md)。

Windows已实测字体选择、光标自动隐藏和部分窗口交互。Linux Wayland已用Noto CJK及原生音频从独立用户目录启动至标题并正常退出。wgpu的Windows Vulkan/DX12合成检查及部分真实场景与CPU对照通过。

## 使用与限制

桌面配置见[运行指南](../../guides/running.md)。默认构建剧情快照；系统存档和剧情槽写入需要 `--user-data-dir`，已记录自动恢复状态的用户目录启动时会恢复相应槽。原游戏目录保持只读。
