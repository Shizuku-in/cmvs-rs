# 《アマツツミ》测试档案

截至 2026-10-29，当前研究对象为用户提供的 PC x86-64 样本；发行版本及补丁号未确认，不据此宣称覆盖其他发行版、汉化版或 Android 包。

## 样本身份

| 字段 | 已确认内容 |
|---|---|
| 游戏标识 | `amatsutsumi` |
| 可执行文件 | `cmvs64.exe`，x86-64，image base `0x140000000` |
| 二进制 SHA-256 | `dc74d2001387ae1aefbdc4204216de5ebb9d3896009280720c4e7a91b42d84f5` |
| 当前编码配置 | 显式 `shift-jis` |

本地路径仅为复现示例，不是身份依据。各脚本、资源、系统存档和音频 DLL 的哈希及验证条件见[研究记录](research.md)、[VM 语义](vm-semantics.md)和[覆盖报告](script-coverage.md)。本文所有原版地址只对上表二进制有效。

## 当前验证

| 项目 | 结果与边界 |
|---|---|
| 结构检查 | 包内 87 个脚本及包外启动脚本共 88 个来源通过解码与入口/标签/直接跳转边界检查；包内、包外同名启动脚本分开统计 |
| 路线重放 | `[1]` こころ、`[2,1]` 響子、`[2,2,1]` 愛、`[2,2,2,1]` ほたる END1、END1 存档后的 `[2,2,2,2]` END2，以及 OP 已在显式预览条件下回到标题 |
| 画面 | 部分真实路径逐帧呈现及抽样检查、独立 Python 对照通过；不同路线检查范围不同，未验证所有中间画面 |
| Windows 原生运行 | 标题、图标/光标、键鼠、OP、部分剧情画面与消息等待实测；品牌音效与标题 BGM 经普通桌面权限验证，完整路线和真实音轨未全程实测 |
| 系统存档 | 已有 CSS1 模板下，新文件导出与独立用户目录的重复保存、备份及重启持久区回读通过；原游戏只读 |
| 剧情存档 | CSV2 解码与部分记录读取已核对；完整快照与 `0x22b5` 恢复未实现 |
| 鉴赏 | 已补齐 `0x0105`、空槽清理、区域配置及默认字体辅助文本构造与位置设置 `0x2383`、布局字段设置 `0x2385`、文字参数设置 `0x2387`、颜色设置 `0x2389` 、字段 +148/+140 设置 `0x238e`/`0x2392` 、图层设置 `0x238f`、内容清理 `0x2386`、字段 +144 设置 `0x2393` 、边界设置 `0x2396` 及第二贴图装载 `0x2397`；停于 `omake.ps3 / 0x49248 / 0x20ca`，缩略图布局与父级遮罩已接入，交互未完成 |
| 其他平台 | macOS、Linux、Android、iOS 尚未完成构建与行为验证 |

五条结局回标题的结果来自记录重放，不代表全分支、全指令、原生完整流程或完整存读档兼容。旧覆盖报告保留采集时快照，鉴赏后续进展不回写历史 PC 数量。

## 使用与待办

桌面配置见[运行指南](../../guides/running.md)。默认启动保留快照屏障；本机系统存档还可能触发尚未实现的自动恢复。进入标题需要显式预览策略，系统存档写入需要单独选择输出方式。

近期优先核对鉴赏 `0x20ca` 及后续输入 及后续命令，补测未覆盖分支、原生完整路线和音轨，随后完善完整剧情快照/恢复与无 CSS1 模板首次保存。自动恢复策略中的游戏 ID 检查不能直接推广到其他作品。
