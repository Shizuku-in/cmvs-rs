## 重现

```powershell
cargo run --offline --release -p cmvs-probe -- "<游戏目录>" --out "local/aoitori/new-run" --checks S1,S2,S3,S5,R1,D1,R2 --without-snapshots --font "<字体文件>" --max-steps 1000000000 --max-routes 8
```

路线重放使用显式 `--without-snapshots`，不能据此认领保存能力。检查剧情开头存读档时去掉该参数，改用 `--checks V1,V2,V3,V4`；默认捕获在活动粒子处仍报未支持，`sn102` 的18,013,298步快照点已复现此边界。

输出目录必须不存在。固定种子0、16ms虚拟帧、鼠标、独立用户目录；原游戏只读。默认放行未复核及推定语义，传入 `--block-unreviewed` / `--block-presumed` 才阻止；运行通过不提升证据等级。探索预算耗尽、停点或失败需分别查看，不能把局部结果视为完整游戏兼容。

已知命令的共享分派迁移已收口，完整架构验收仍待完成，见[分派设计](../../design/dispatch.md)第25节。类型2/5/6及 `0x22a8` 图像碎片效果已接入身份绑定的研究入口；碎片效果的长路线重放已越过停点，剧情开头存读档已验证；后续推进回看禁则 `0x23b8`、活动效果快照、解锁轮次及更多保存点。
