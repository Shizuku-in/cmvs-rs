## 重现

```powershell
cargo run --offline --release -p cmvs-probe -- "<游戏目录>" --out "local/aoitori/new-run" --checks S1,S2,S3,S5,R1,D1,R4 --font "<字体文件>" --max-steps 1000000000 --max-routes 16 --max-rounds 4
```

上例使用正常快照模式。检查剧情开头存读档时改用 `--checks V1,V2,V3,V4`；`sn102` 的sakura01保存点完成同会话读回及字节往返验证，不能外推到任意保存点。

输出目录必须不存在，预算耗尽和运行失败分别记录；不得把局部结果视为完整游戏兼容。

## 验证条件

自动运行使用固定种子 0、16 ms 虚拟帧、合成输入及日文字体，写入独立用户目录，原游戏只读。默认允许未复核和推定命令；运行成功不提升档案证据等级。无快照预览与正常快照结果分别统计。

## 构建差异

以下绑定本页 x64 哈希，不提升命令证据等级；x86 未独立复核语义。

| 命令 / 状态 | 已支持行为与边界 |
|---|---|
| 初始变量 | 整数 / 位 / 浮点 / 字符串按已核对物理银行零初始化，范围外仍未知 |
| `0x23ac` | 读写字体 cell advance 模式；OpenType 使用 advance 度量，与墨迹宽度分开 |
| `0x210b`、`0x2152`、`0x2154`、`0x2157`、`0x2159`、`0x238b` | 字体 cell 布局、窗口即时 / 渐显 / 追加 / 轮询和辅助输出，共用 `font-cells` 变体 |
| 比例注音 | 最多 32 个双字节基字；普通注音按实际宽度居中，等数中点逐字对齐，保留无符号 22.10 取整和环绕；base / ruby 显现时钟分开 |
| `0x211d` | 回收 8 字节；结果 0 / 1 / 2 / 4 为成功、最大行宽、行数、末行宽；测量后恢复画笔，保留已核对 scratch 效果 |
| `0x23b8`、`0x23b9`、`0x23bb` | 辅助文本的禁则、字节 / 像素测量；字号变化图集只在完整覆盖且不破坏活动字形时重绘 |
| `0x203b` 模式 17 | `gray=(76R+150G+29B)>>8`，RGB 再乘颜色分量并右移 8，alpha 不变；保留两次独立截断 |
| `0x22ed` | 后台音频开关，与失焦脚本 / 场景运行开关分开 |
| `0x22a2`、`0x22a5`、`0x22a6` | 类型 2 下落、类型 5 精灵及类型 6 碰撞粒子，独立对象池、共享 CRT 随机数；类型 5 每粒子初始化 8 次、重生 2 次随机取值 |
| `0x22a8` | 类型 8 图像碎片接管源对象；快照按原版丢弃瞬态 |
| 类型 5 推进 | 位移 delta 上限 500 ms，十格动画每格 100 ms、动画 delta 上限 200 ms；模式高位选择投影尺寸及重生范围 |
| `0x010f` | 浮点表达式系统结果读写保留原始浮点位，不通过整数转换 |
| 剧情快照 | 文字 v3；`0x800` 类型 2 / 5 为 60 字节、类型 6 为 52 字节创建参数记录，类型 8 为 4 字节空恢复 |
| 效果恢复 | 按槽重新加载图像、消费共享随机数初始化，不恢复粒子瞬时位置；候选失败不提交池或随机数 |
| `0x749` | 场景碰撞顶点：零头、数量和数量×3 个 f32 原始字；最多 128 个有限顶点，保留负零及空流与未分配的区别 |

原生图形、GDI 度量与 OpenType 不保证逐像素一致。粒子、快照、碰撞及文字算法的具体实现分别见 core 的 `effect_objects`、`snapshot`、`message/font_cells`；未知类型、版本和非有限参数仍拒绝。
