## 重现

```powershell
cargo run --offline --release -p cmvs-probe -- "<游戏目录>" --out "local/aoitori/new-run" --checks S1,S2,S3,S5,R1,D1,R2 --font "<字体文件>" --max-steps 1000000000 --max-routes 8
```

输出目录必须不存在。固定种子0、16ms虚拟帧、鼠标、独立用户目录；原游戏只读。默认放行未复核及推定语义，传入 `--block-unreviewed` / `--block-presumed` 才阻止；运行通过不提升证据等级。探索预算耗尽、停点或失败需分别查看，不能把局部结果视为完整游戏兼容。

已知命令的共享分派迁移已收口，完整架构验收仍待完成，见[分派设计](../../design/dispatch.md)第25节。类型2/5/6效果已接入身份绑定的研究入口；当前优先核对 `0x22a8` 图像碎片效果，再推进解锁轮次及剧情存读档。
