## 重现

```powershell
cargo run --offline --release -p cmvs-probe -- "<游戏目录>" --out "local/aoitori/new-run" --checks S1,S2,S3,S5,R1,D1,R4 --font "<字体文件>" --max-steps 1000000000 --max-routes 16 --max-rounds 4
```

上例使用正常快照模式；旧的 `--without-snapshots` 研究记录不能据此认领保存能力。检查剧情开头存读档时去掉该参数，改用 `--checks V1,V2,V3,V4`；类型5活动粒子的旧保存屏障已越过，`sn102` 的sakura01保存点完成同会话读回及字节往返验证，不能外推到任意保存点。

输出目录必须不存在。固定种子0、16ms虚拟帧、鼠标、独立用户目录；原游戏只读。默认放行未复核及推定语义，传入 `--block-unreviewed` / `--block-presumed` 才阻止；运行通过不提升证据等级。探索预算耗尽、停点或失败需分别查看，不能把局部结果视为完整游戏兼容。

已知命令的共享分派迁移已收口，完整架构验收仍待完成，见[分派设计](../../design/dispatch.md)第25节。类型2/5/6及 `0x22a8` 图像碎片效果已接入身份绑定的研究入口；碎片效果的长路线重放已越过停点，剧情开头存读档已验证；正常快照四结局与9个通关追加场景已完成自动重放；其他保存/跳转点及原版存档互操作不作泛化保证，原生窗口交互与听感由用户后续检查。
