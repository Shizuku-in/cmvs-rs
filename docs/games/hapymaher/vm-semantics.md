## 0x203b：水平模糊模式256 / 512（2026-11-02）

case `0x140076587` → `0x140062ae0`：SP向下为对象、图名、模式、颜色、额外参数，回收20字节、返回 `0x4014`；正常结果0表示加载是否成功。有效对象读取链 `0x140034620` → `0x14002e220` → `0x14002c6e0`，后者在纹理上传前改写解码像素并保留三字滤镜参数。本作图像字段比后期构建前移512字节，不改变磁盘图像v3的字段顺序。

模式256为按行三角权重模糊，512为按行均匀权重模糊，均非纵向处理。额外参数低16位为半径r、高16位为步长s，两者零均取1。对每个目标x，从偏移-r起以s递增至≤r；只累加行内样本，256权重为 `r-abs(offset)+1`，512权重为1。RGBA四通道都参与，以u32回绕累加后除有效权重和、截断到byte；颜色字不参与。每行先写独立缓冲，再覆盖原行，不从同一行已经模糊的像素采样。

部分半径/步长会导致边缘无有效样本，原版会除零；Rust明确报错并保留旧图、PC及参数。未支持模式仍拒绝，不把其他滤镜当空操作。图像滤镜参数随换图保留，快照图像加载允许256/512并从原始资源重新施加；PB3解码算法未改。

实际调用为 `sky021.ps3 / 0x1b87a`（256）、`intcode.ps3 / 0x12896`（512），额外参数均 `0x00020010`。真实资源分别1376×1280、1820×1024；全部3624960像素与独立NumPy参考逐字节一致（包括alpha），输出哈希分别 `e47c3f99521d9fab3ec37e5add8a8c38da7016ec5ad7dcbce6c469d2fecf80e9`、`cf9909827ceee0d09e0cec18b5d2503a66ee5b5c9f936b7fd709e6ea39bc329e`。这是算法参考对照，未截取原版输出画面。

只读伪代码证据 `local/hapymaher/filter-x64.json`，SHA-256 `d683bb3a5656edc2e992424b6f0d6e9f72012ebd145ca3d05df09aac308e9c59`；样本提取程序、独立参考及输入/输出哈希位于 `local/hapymaher/filter-sample.rs`、`local/hapymaher/filter-samples/check.py`、`comparison.json`。合成检查覆盖两种权重、边缘、零默认值、采样步长、alpha、参数保留及无样本时的事务失败。

## 0x22a8：类型8图像碎片（2026-11-02）

case `0x140077eaa` → `0x140072cb0`，SP向下四字为效果槽、源对象槽、片边长、第二参数；效果槽0..3且源对象存在时，释放旧效果、构造0xa0字节容器，经 `0x1400387e0` 设置类型8，接管源对象并清空普通对象槽。返回 `0x4010`、回收16字节，不写结果；非法源槽在原版可能越界，Rust保留显式错误。

绑定/初始化 `0x1400012a0` / `0x1400012b0`：从源图像取宽高，分别向上除20决定网格；片边长控制源矩形和中心，固定网格除数不随参数改变。独立对象使用父图像，每片36字节状态，按行列顺序消耗4次CRT rand；方向、行延迟、速度、漂移步长与已有碎片实现一致。第二参数被保存，本次初始化/更新不读取它。

更新 `0x140001760` 使用从创建开始的累计毫秒时间，等延迟后每帧累加横向漂移，以累计时间/速度求下落距离，以回绕的 `360*time/10000%360` 求旋转。缩放实参被Hex-Rays伪代码省略：汇编 `0x14000186f..0x1400018a2` 明确将时间除常量7500、钳制到0..1，再把 `1-t` 同时放入xmm1/xmm2调用 `0x140033bc0` → `0x14001ab90`。常量 `0x1400cb9d4/0x1400cb9d8` 为1.0/7500.0。因此本作同样逐渐缩小，不新增“不缩小”的变体。

完成查询 `0x140037840` → `0x140001290` 返回完成标志的0/-1，全部片落过图高+32后置位，不自动释放。更新分派 `0x140037b30` 的类型8分支调用上述推进；绘制 `0x140037e70` → `0x1400443f0` → `0x140036770` 遍历接管对象及独立列表，与共享图像、父显隐及场景层呈现模型一致。释放仍经过四槽效果析构；未知活动效果快照继续拒绝。

### 0x22ae：碎片完成查询

case `0x140077eb7` → `0x140072370`，SP-4为效果槽，返回 `0x4004`。槽0..3时调用上述类型分派，把类型8的未完成0/完成ffffffff写入系统整数0；其他结果槽不变。越界槽只回收参数、不写结果。原版空效果会解引用空指针，Rust明确报错并保留PC、参数和结果；尚未核对的其他效果类型也拒绝。本构建该命令单独绑定 `variant=fragments`，不是无条件开放所有构建或类型的查询。原始包装证据 `local/hapymaher/fragment-query-x64.json`，SHA-256 `72b327dc79547a0d352da221d50aab6a1e4d8e5bf91b1fd9fd9c43aea0b196ee`。

将本构建 `0x22a8` / `0x22ae` 绑定 `variant=fragments:x64:<本页SHA-256>`，命令仍为Unreviewed且服从禁止未复核命令策略；新增类型8完成查询，未修改其他构建的绑定或碎片推进算法。只读证据（17个函数、推进汇编及浮点常量）保存在 `local/hapymaher/fragment-effect-x64.json`，SHA-256 `6b1196b175176e5ce6537b71a1adb14f60b80521ec3518381edc8bf417ad7dd7`；路径停点与运行结果见[研究记录](research.md)。
