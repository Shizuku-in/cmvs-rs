## 构建差异

地址及变体仅绑定本页 x64 哈希，x86 未独立复核语义；命令仍为 `Unreviewed`。

| 范围 | 已支持行为与边界 |
|---|---|
| 快照 | `TextV2`：文字 v2 不含 v3 的 208 字节禁则块；窗口 / 场景 v3、图像 v3、绘制 v4，缓冲 3 MiB、CSV2 头 600 字节 |
| 子对象与按钮 | 子表 512 槽；拒绝任何嵌套场景中 ≥512 的子槽及 `0x8c8` 按钮列表；活动粒子仍拒绝 |
| `0x203b` | 五参数，回收 20 字节，结果 0 为加载成功；模式 256 / 512 分别为逐行三角 / 均匀权重模糊，RGBA 都参与 |
| 模糊参数 | extra 低 / 高 16 位分别为半径 / 步长，零取 1；只采行内原像素，u32 回绕累加后除有效权重；无有效样本报错 |
| `0x22a8` | 效果槽、源对象槽、片边长、附加参数，回收 16 字节；类型 8 接管源对象，按宽高向上除 20 建网格，每片消耗 4 次共享随机数 |
| 碎片更新 | 按行延迟、累计时间及逐帧漂移运行，旋转保留 u32 回绕，7500 ms 内逐渐缩小；第二参数保留但不参与已核对的推进 |
| `0x22ae` | 回收 4 字节，类型 8 未完成返回 0、完成返回 −1；越界不写结果，空槽和未支持类型明确报错 |

滤镜的真实输出与独立 NumPy 对照一致；碎片前 120 帧的 276480 组状态对照一致，无输入时 369 帧后自然释放。均不代表原版逐帧像素或任意保存点兼容。
