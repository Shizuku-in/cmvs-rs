### 首次剧情停点与路径修复

交互探针使用 `--checks P1,P2,R2,I1,I2,I3,I4,I5 --without-snapshots --max-steps 5000000 --max-routes 4`，其他参数同上。原始R2在291195步、`sky01.ps3 / 0x4f74 / 0x2308` 读取 `mv03.cmv` 时失败：启动脚本 `text+0x00f2` 注册的场景影片封包路径是 `data\pack\\video.cpz`，共享路径解析器拒绝重复分隔符。

现已允许相对路径内部重复的 `/`、`\` 分隔符；仍拒绝起始/末尾分隔符、`.`/`..`、盘符、非ASCII和根目录外的规范化目标。合成回归覆盖重复/混合分隔符读取及拒绝路径。修复后仅重跑I2、I5、R2，三项均越过旧路径错误，随后因无快照研究策略报 `no snapshot image was built (--continue-without-snapshot)`。R2推进到802058步、10130次让出、`sky01.ps3 / 0x2bc26`；尚未到选择点或返回标题，不能算路线通过。首次与修复后报告分别位于 `local/hapymaher/initial/interaction/`、`local/hapymaher/initial/path-fix/`。
