### 类型 4 雨丝

`0x22a4 → 0x45379b → 0x44fcb0 → 0x424c00 → 0x42ec80` 读取槽、图像、mode、四个浮点字和发射间隔，返回 `0x4020`，不写系统结果。四个效果槽共用生命周期和 CRT 随机数；有效槽替换旧效果。资源读取失败保留旧效果及参数供重试。

`0x42ed00` 创建最多 2,048 条动态雨丝，每条消耗两次随机数确定 X/Z，起点 Y=150，图像区域 6×112、轴心 (3,112)、坐标模式 2；mode 选择水平范围、深度范围和参考深度。`0x42f240` 将发射余量限制为 1,000ms，严格大于间隔才发射，`0x1000` 位每次发射两条；活动雨丝按未截断的时间差、角度和速度移动，Y≤−50 时删除。非法/未核对的范围模式、零间隔及非有限参数明确报错，避免模拟原程序的未初始化值或死循环。f64 建模 x87 中间值并保留明确的 f32 落栈点，不承诺任意输入的 80 位逐位等价。

类型 4 存档为 60 字节创建模板（v1/type4、六个参数字、32 字节名称），`0x424020` 写入、`0x4240c0` 读取后重新初始化，不保存活跃雨丝。仅本构建开放此快照类型；其余活动效果、特殊图像和未支持的影片控制状态继续显式拒绝。

## 验收运行

```powershell
cargo run --offline --release --features desktop,audio-output --bin cmvs-desktop -- "<游戏目录>" --encoding shift-jis --user-data-dir local/asunana/play-user --audio native --font "<日文字体文件>"
```

使用独立 `play-user` 保留人工验收进度，不混用探针用户目录。Windows 可用系统 `msgothic.ttc` 字体；已构建的程序为 `target/release/cmvs-desktop.exe`。正常存档无需 `--continue-without-snapshot`。

合成回归覆盖构建边界、输入按下/持续按住及重复查询、画布与子槽、旧坐标动画、文字对话框，以及雨丝发射边界、随机数推进、移动/清除、资源失败重试和创建模板。仍待人工验收完整声音、交互手感、游戏内存读档页面与鉴赏页面；未验证其他平台或所有特殊保存点。

验证：core 单元与受影响的 profile/variant、dispatch、settings、scene/projection、particles 集成回归通过；core/根包 all-targets 严格 Clippy、格式与差异检查、release 桌面音频构建通过。未运行全仓库测试及跨平台构建。
