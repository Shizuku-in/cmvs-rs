# 游戏测试目录

每款游戏独立记录版本、二进制身份、实际运行范围及未实现项。“已测”只对档案里的版本与运行条件成立。

| 游戏 / 标识 | 样本与平台 | 验证范围 | 当前限制 |
|---|---|---|---|
| [アマツツミ / amatsutsumi](amatsutsumi/README.md) | PC x86-64；样本 SHA-256 见档案 | 88/88 来源结构检查；五条结局及 OP 记录重放回标题；部分 Windows 原生实测 | 鉴赏 `0x2389`；完整剧情恢复和原生完整路线未验证 |
| [クロノクロック / chronoclock](chronoclock/README.md) | PC x86-64 1.00；样本 SHA-256 见档案 | 摸底：CPZ6 封包；86/86 来源结构检查；无窗口 trace 经标题进入オートデモ | 停在 `cdemo.ps3 / 0x2026`；现有语义没有按本作二进制复核 |

新增作品时复制[档案模板](TEMPLATE.md)，填写已确认信息，再向本表追加一行；研究步骤见[研究约定](../research.md)。

游戏素材、解包剧本和 IDA 数据库留在仓库外。可将本地实验输出按 `local/<游戏标识>/<版本或实验名>/` 分类，避免同名脚本、存档和日志混用。
