### 碰撞粒子

`0x22a6 → 0x45761b → 0x453c00 → 0x426890 → 0x431b50`：槽、图像、mode、两个浮点字和粒子数量，返回 `0x4018`，不写系统结果。创建 `0x431750` 每粒消耗五次 CRT 随机数（含一次丢弃），44 字节记录、32×32 图像、轴心 (16,16)。更新 `0x431ba0` 将时间差限制到 120ms，从场景槽 20–27 收集碰撞面，使用第一个命中面，接近接触面时淡出、越过后回收；回收消耗两次随机数。

x87 分支以 f64 表达随机数中间值，保留明确 f32 落栈点和百分位截断。下落步长在 `0x431c9b` 先把 f64 商存为 f32 再相减；53 位精度下这两步与 f32 运算逐位一致，此前按单次 f64 舍入的实现已更正。合成 Python struct/f64 参考验证固定种子创建记录。碰撞求交复用现有浮点实现，不承诺任意输入的 80 位逐位一致或原版像素一致。

`0x2330 → 0x449da0 → 0x422c10` 创建网格，`0x2331 → 0x449de0 → 0x422c80` 释放，`0x2332 → 0x449e20 → 0x422cb0` 加顶点；保存 `0x4255d0` 写网格版本、顶点数及 XYZ。效果写入 `0x425740` 生成 52 字节 v1/type6 创建模板，加载时重新初始化粒子，不保存活动粒子。仅为本构建开放此效果快照类型，其余未核对类型保持显式拒绝。

### 淡变粒子（类型 7）

`0x22a7 → 0x457623 → 0x453d20 → 0x426960`：参数、四槽替换、`0x4018` 返回与 `0x22a6` 相同，但建立 80 字节类型 7 对象。`0x431f50` 载入图像，`0x432500` 存 mode/基准 Z/速度/数量于 +32 起，调用的初始化 `0x431fb0` 与类型 6 的 `0x431750` 逐条指令相同（仅字段偏移 +0x14 与本地跳转表不同），故复用其五次随机数与 x87 落栈模型。mode 字节 2 模 3 为淡变相位（0 不变、1 淡入、2 淡出），字节 1、字节 0 乘 100 为延迟与时长（毫秒）。

更新 `0x4322c0` 不读碰撞面：自创建起的未截断时钟按无符号比较计算整体透明度（延迟前淡入为 0、淡出为 255，时长为零即刻完成，`255×t` 保留 32 位回绕）；移动同类型 6 限制 120ms 并以 f32 商相减，Y 小于零时两次随机数重置 X/Z、Y 加 75、清缓存接触高度，然后把整体透明度写入每个粒子。写入 `0x425740` 经 `0x431f40` 输出与类型 6 同布局的 52 字节 v1/type7 模板，读取 `0x425850` 经 `0x432500` 重新初始化，淡变时钟随之重启。实现以 `variant=fading-particles:x86:<本页 SHA-256>` 绑定，保持 Unreviewed；复用类型 6 粒子池、渲染及释放路径，不采集碰撞网格。脚本共 788 次 `0x22a7` 调用。

## 运行

```bash
cargo run --offline --release --features desktop,audio-output --bin cmvs-desktop -- \
  "/run/media/gkouen/New Volume/Download/Purple Software/2009-08-28_MEMORIA" \
  --encoding shift-jis --user-data-dir local/memoria/play-user --audio native \
  --font /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
```

正常游玩使用独立 `play-user`，无需 `--profile` 或 `--continue-without-snapshot`。
