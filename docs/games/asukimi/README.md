## 构建差异

差异只绑定本页 x86 哈希，519 个处理命令保持 `Unreviewed`。

| 范围 | 兼容规则 |
|---|---|
| 画布 | 旧版 `CMVS_SYSTEM_MAIN/WINDOW_SIZE`，样本 800×600；子对象表 256 项 |
| `0x201d` / CSS1 | 原版无作品 ID 命令，CSS1 偏移 68 固定零；仅作为本构建的格式字段，不推断作品身份 |
| `0x2187`、`0x219c`、`0x219e`、`0x21a0`–`0x21bc`、`0x22f0`–`0x22f5` | 旧版队列 / 输入变体；查询按下边沿及 held，不自动消费；配套消费命令仅清边沿 |
| `0x203d` | 父槽与负子槽参数，从最近完成设备帧构建图像，回收 8 字节，输出强制不透明；不消费延迟截图 |
| 类型 1 / 2 相机 | 分别使用深度阈值 0 / 9，近端淡入和类型 2 的平方深度缩放；f64 模拟 x87 中间值，不保证任意输入逐位一致 |
| `0x21fa` | 旧版低字节模式 `0x20` / `0x21` / `0x30` / `0x40`，保留高位振幅、百分位截断、到期吸附和关键帧进度；不扩展未核对序列入口 |
| `0x203b` 模式 1 | `gray=floor((R+G+B)/3)+1`，RGB 各为 `floor(gray*color/256)`，保留 alpha；颜色高字节及 extra 不参与 |
| `0x2100` | 八个文字槽，空 / 非空字体均重新选择持久字体对象 |
| `0x2248`–`0x224b`、`0x224f` | 独立 24 槽音频预加载池；预加载 / 释放 / 停止不受 SE 开关限制，播放 / 音量受限制；Web 未支持这些操作 |
| `0x20d8` | 有符号角度和半径，角度乘 100 保留回绕，正余弦结果向零截断写结果 1 / 2 |
| `0x213c` / `0x22bc` | 存档评论对话框与元数据更新；原版确认时过滤半角，取消时保留原评论 |

### 旧版快照

文字 v1 无逻辑尺寸和扩展禁则块，按设备尺寸恢复；8 文字、4 窗口（16 按钮）、256 主对象及 256 子槽。窗口 / 场景 v1，图像 v2 少 alpha 字，绘制 v3 少 depth bias，动画 v1 为 32 项。相机 v2 读回吸附运动目标并停止；场景影片 v2 为 286 字节。BGM 用 `0x300` 字符串，无现代 `0x6e0`。

按钮读回按原版恢复为空组；未支持的 mask、粒子、列表、碰撞和特殊图像状态拒绝。保存使用独立用户目录，不用无快照模式认领存档能力。标题闲置演示的 `cdemo.ps2 / 0x1f574 / 0x012e` 浮点存储类型仍未支持。

## 验证条件

自动检查使用种子 0、16 ms、鼠标、日文字体及独立用户目录，游戏只读。无窗口重放、算法对照、原生设备和物理交互分别统计；未复核命令的运行放行不提高证据等级。原版存档互操作、任意保存点及其他平台未完整验证。

## 运行

使用[桌面运行](../../guides/running.md#桌面运行)，选择 Shift-JIS、默认快照及独立用户目录。探针需完整画面时加 `--render-frames`，以完成帧提供设备抓图；未生成画面时抓图明确失败。
