## 构建差异

命令与布局绑定本页 x64 哈希，x86 未独立复核语义。

| 范围 | 已支持行为与边界 |
|---|---|
| 画布与脚本 | 1024×768，由 `WINDOW_RESOLVING/BASE` 读取；RESET 返回 `main.ps2` |
| `0x2007` | 无参数，u32 毫秒差除 1000 写结果 0，返回 `0x4000`；使用显式帧时钟，不等于墙钟暂停行为 |
| 整数字面量赋值 | 立即数左值丢弃写入，表达式仍保留右值；不扩大未知存储或浮点路径 |
| `0x22a5` | 类型 5 精灵粒子，回收 32 字节；每粒子初始化 8 次共享随机数，位移 delta 上限 500 ms |
| 快照 | 文字 v2、场景 v3、图像 v3、绘制 v4，512 子槽，无 `0x8c8` 列表；未知布局拒绝 |
| 活动效果 | 仅类型 5 的版本 1 / 60 字节 `0x800` 创建参数；读回重新初始化，不保存瞬时粒子位置 |
| `0x215e` | 回收 4 字节，结果 1 / 2 为窗口原点，其他结果保留 |
| `0x22be` | 回收 12 字节，修改存档头 532 / 536；只写独立用户目录，原子替换保留其余载荷 |
| `0x230e` | 六参数、回收 24 字节；接受归档模式 2 / 3，3 用有界内存解码；散文件模式 0 / 1 拒绝，读回将 3 归为 2 |
| `0x231e` | 回收 4 字节，返回当前帧，空槽为 0；不推进播放器 |

使用[桌面运行](../../guides/running.md#桌面运行)或[探针入口](../../guides/cli.md)，提供 Shift-JIS 字体和独立用户目录。正常保存使用默认快照模式；未知效果或记录明确报错。输出目录须全新，真实数据不入库。
