## 实现与验证

| 项目 | 当前支持与验证范围 |
|---|---|
| 启动与资源 | 支持 CPZ3、PS2A 和 CMV4/JBP1；标题、序章及 OP 可运行 |
| 画面与特效 | 1024×614 画布、旧版类型 1 相机及动画轨道；类型 1–3、0x50–0x57 特效已接入 CPU/wgpu 绘制 |
| 存读档 | 支持独立旧版快照、存读档页面和快存快读；场景、文字及类型 3 特效恢复已验证 |
| 页面与设置 | 存档、读档、设置、回想和退出确认可进入及返回；支持配置持久化与恢复默认 |

| 剧情与选择 | 已验证分支可返回标题；完整路线兼容性尚未确认 |

## 关键适配

- `0x2100`：支持本构建的旧版文字创建与显式字体选择，供存读档页面使用。
- `0x22ec`：支持特殊全屏设置的查询、修改及持久化，并统一画面原点与鼠标坐标映射。
- `0x22a3`：支持旧版类型 3 飘落粒子的创建、更新、绘制和释放；快照保存 52 字节创建参数，读档重新生成粒子。相关分支、活动存档恢复与 CPU 绘制已验证。
- `0x2297`：支持类型 0x57 背景、旋转圆环与环绕粒子，以及参数 10 的贴图切换；实际资源加载、CPU 绘制和释放已验证。快照仅保存类型头，读档清除。

## 已知限制

- `0x213b`（DVD 认证激活失败处理路径中的命令）未实现。
- 完整路线、鉴赏页面、回想内容一致性及原生交互尚未完整验证。
- 原生全屏、音频听感、其他平台及原版画面对照仍待验证。
