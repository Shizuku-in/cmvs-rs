## 实现与验证

| 项目 | 当前支持与验证范围 |
|---|---|
| 启动与资源 | 支持 CPZ3、PS2A 和 CMV4/JBP1；标题、序章及 OP 可运行 |
| 画面与特效 | 1024×614 画布、旧版类型 1 相机及动画轨道；类型 1–3、0x50–0x57 特效已接入 CPU/wgpu 绘制 |
| 存读档 | 支持独立旧版快照、存读档页面和快存快读；场景、文字及类型 3 特效恢复已验证 |
| 页面与设置 | 存档、读档、设置、回想和退出确认可进入及返回；支持配置持久化与恢复默认 |
| 音频 | 支持 Ogg、PCM WAV 及混音增益；实际音频资源解码通过 |
| 剧情与选择 | 已验证分支可返回标题；完整路线兼容性尚未确认 |

## 关键适配

- `0x2100`：支持本构建的旧版文字创建与显式字体选择，供存读档页面使用。
- `0x22ec`：支持特殊全屏设置的查询、修改及持久化，并统一画面原点与鼠标坐标映射。
- `0x22a3`：支持旧版类型 3 飘落粒子的创建、更新、绘制和释放；快照保存 52 字节创建参数，读档重新生成粒子。相关分支、活动存档恢复与 CPU 绘制已验证。
- `0x2297`：支持类型 0x57 背景、旋转圆环与环绕粒子，以及参数 10 的贴图切换；实际资源加载、CPU 绘制和释放已验证。快照仅保存类型头，读档清除。

## 已知限制

- `0x213b`（DVD 认证激活失败处理路径中的命令）未实现。
- 完整路线、鉴赏页面、回想内容一致性及原生交互尚未完整验证。
- 原生全屏、音频听感、其他平台及原版画面对照仍待验证。

## 构建差异

所有差异只绑定本页 x86 哈希；运行成功不升级未复核命令。

| 范围 | 兼容规则 |
|---|---|
| 初始化 | 整数 / 位 / 浮点 / 字符串银行分别为 4096 / 262144 / 2048 / 128；CSS1 的缺失游戏标识写零 |
| 画布 / 子槽 | 旧版 `CMVS_SYSTEM_MAIN/WINDOW_SIZE` 及显式尺寸配置；样本 1024×614，子槽 256 项 |
| `0x22c0` / `0x22c1` | `activation-pass`：回收参数，结果为参数是否等于 1；不运行原版激活程序或驱动器校验 |
| `0x20a5` | 混音器总增益，按无符号钳到 256；不当作播放速率 |
| `0x2017` / `0x2018` / `0x2032` | 独立立绘 / 近景封包登记及下一次读取缓存提示；资源查找保留构建差异 |
| `0x21c0`–`0x21c2` | 窗口对象 / 子对象缩放轨道，帧增量上限 200 ms，支持线性及旧版正弦 |
| `0x2270`–`0x2274` | 设备视图的停止、等待、查询与位置 / 角度过渡；恢复快照清除视图运动 |
| 旧版轨道 / 极坐标 | 保留百分之一度、负余数、旧正弦计算顺序及旋转保持规则，不套用现代构建精度 |
| 类型 1 / 3 | 雨丝、飘落粒子的独立池、共享随机数、帧推进、呈现与创建参数恢复 |
| 类型 `0x53`–`0x57` | 双片遮罩、魔法图形、精灵及背景 / 平面 / 圆环效果；未知参数继续拒绝 |
| 相机 / 快照 | 类型 1 投影；独立旧版文字 / 场景布局，具体标签见[快照格式](../../formats/snapshot-format.md) |
| `0x2100` | 旧版文字创建、显式字体选择，文字槽上限 8 |
| `0x22ec` | `WINDOW_FULL_MOVE_USE` 查询 / 写入；全屏未缩放时可将画布原点放在左上角，鼠标使用同一转换 |
| 渲染 | 震动遮罩按层次合成；世界网格在透视除法及细分前剔除完全离开视野侧面的单元 |

磁盘格式和公共后端契约统一见[文档导航](../../README.md)，各效果的精确运算留在 core 实现及有效测试中。
