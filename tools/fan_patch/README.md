# 汉化补丁转换工具

将支持的汉化补丁转换为 cmvs-rs 可读取的脚本和资源。需要原版游戏及对应补丁；工具按 SHA-256 检查输入版本。

## 支持的游戏

| 游戏 | 转换与启动说明 | 输出编码 | 引擎 profile |
| --- | --- | --- | --- |
| 明日の君と逢うために | [asukimi](asukimi/README.md) | GBK | `cmvs-20071117` |
| 未来ノスタルジア | [miranosu](miranosu/README.md) | UTF-8、GBK | `cmvs-20110525` |
| ハピメア | [hapymaher](hapymaher/README.md) | UTF-8、GBK | `cmvs-20130131` |
| クロノクロック | [chronoclock](chronoclock/README.md) | UTF-8、GBK | `cmvs-20150405` |

## 使用约定

从仓库根目录执行命令。需要 Python 3.10+；除 asukimi 的转换步骤外，还需要本项目要求的 Rust/Cargo 和已缓存的依赖。启动桌面版也需要 Rust/Cargo。

输入只读。输出目录必须不存在，且位于原版游戏目录之外。转换器复制原版资源、程序和配置，再写入转换结果；不安装补丁 exe/DLL 或剧情存档。完成后生成 `conversion.json`，记录编码、输入身份和输出校验值。失败留下的目录不能直接使用，重试时另选新目录。

运行时显式指定游戏的 `--profile`、输出编码和包含所需字形的字体，使用独立的 `--user-data-dir` 保存设置及进度。转换器保留的原版 exe 供身份识别，游戏通过 cmvs-rs 启动。

## 选择编码

miranosu、hapymaher、chronoclock 的转换命令支持：

| 转换参数 | 行为 | 启动参数 |
| --- | --- | --- |
| `--encoding utf-8` | 默认值，保留源文本字符；也接受 `utf8` | `--encoding utf-8` |
| `--encoding gbk` | 使用旧版 GBK 输出规则 | `--encoding gbk` |

GBK 模式中，hapymaher 将 `♪`、`・` 分别替换为 `☆`、`·`；chronoclock 另将 `䇲` 替换为 `筴`。其他无法表示的字符会报错。UTF-8 模式不做这些替换，但受运行时字形模型限制，拒绝 BMP 之外的字符；两种模式都拒绝文本内嵌 NUL。

两套输出请使用不同的新目录和独立用户目录。切换编码须从原始游戏和补丁重新转换；旧输出中已被替换的字符不能靠再次转码恢复。

asukimi 当前直接保留补丁的 GBK 文本，没有 `--encoding` 转换参数。添加 UTF-8 输出需要重定位字符串引用；实际补丁存在字符串内部引用及当前离线指令解析器不支持的代码，因此这条转换路径尚未实现。运行时本身支持 UTF-8。

## 验证范围

编码选择、字符串引用重定位和资源封包有自动测试。各游戏已有的实际运行记录来自此前 GBK 输出，不能作为新增 UTF-8 输出的完整实机验证。完整路线及原版存档互操作尚未验证；各补丁的已知问题见游戏说明。
